The new Moon mode uses a circular Sun-relative reference frame with a 29.53059-day synodic phase cycle. The view is north-up. Sizes and distances are enlarged for teaching. Orbital inclination, eclipses, libration, calendar dates, and local sky orientation are not simulated. New moon is dark, first quarter right-lit, full moon bright, and last quarter left-lit. The near side is held facing Earth by synchronous rotation in this simplified frame.
