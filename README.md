# Learning Planet

提供國小學生使用的五科互動學習網站。登入後從數學、國文、英文、自然與實驗五顆學習星球出發，進行闖關、朗讀、評量與科學互動實驗。

## 目前功能

- 一、二年級數學題型與限時闖關
- 形狀偵探隊：平面形狀、正方體／長方體及積木數量
- 小一立方體數量：排、柱、層、加法與數量估計
- 圖形觀察與拼圖：旋轉、方向、相同／不同圖形與方格組合
- 數一數與比多少：分類計數、多少比較、相差與估量
- 順序與位置推理：生活先後、自然變化、左右次序與圓形位置
- 小二立方體空間推理：長寬高、前後遮擋、俯視、補成立體與乘法估計
- 測量實驗室：時鐘讀寫、重量比較及量角器判讀
- 可擴充的 `math-games.json` 遊戲題庫
- 200 字國文學習庫及聽音選字
- 英文字彙、拼字、文法拖曳與心智圖關聯
- 自然科單元與獨立科學實驗模組
- 題目自動朗讀、靜音及自動下一題控制
- 班級排行、成就、簽到、XP 與星星幣
- 獨立星光扭蛋機與蒐集圖鑑
- 教師端學生、班級與字彙設定
- 本機體驗帳號 `DEMO / DEMO`（固定禁止 Firebase／Google 綁定）
- 登入、密碼恢復與教師設定欄位支援密碼顯示／隱藏

本專案不包含衣櫃或造型獎勵商城；扭蛋以獨立遊戲入口保留。

## 線上發布

`main` 分支更新後，GitHub Actions 會自動部署至 GitHub Pages。

## 本機預覽

請透過本機 HTTP server 開啟 `index.html`；不要直接使用 `file://`，否則 Firebase 登入、資料載入與部分瀏覽器功能可能無法正常運作。

## Firebase 登入設定

教師、管理員與學員帳密登入需要在 Firebase Console 的 Authentication → Sign-in method 中啟用 Email/Password。若未啟用，所有帳密都會被 Firebase 拒絕，即使帳號與密碼正確也無法登入。

## 資料與隱私

目前學習紀錄保存在使用者瀏覽器的 localStorage，不會跨裝置同步。正式讓真實班級使用前，應加入伺服器帳號、權限、資料庫、備份及隱私政策；公開版本請勿預載真實學生個資。
