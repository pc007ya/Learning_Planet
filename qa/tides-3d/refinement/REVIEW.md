# 海面與操作考核補強

本輪基底 2359d21，沿用同一 Draft PR #7，不合併、不部署。

## 實際差異

- 原材質僅是固定透明度／邊緣光，另有三個水殼線框。現在移除線框，以連續世界座標波紋、深淺吸收色、日夜光感與局部反光表現水面；沒有使用外部圖或程式。波紋只改變光感，不改變 P2 殼、模型水位與曲線。播放時細節移動，暫停／背景時停止；減少動態設定下保持靜態。
- 原挑戰只有選圖。新增實際調月球的大潮、小潮、1.90–2.10 指定潮差三關；判準直接讀模型角度與 2×tideAmplitude。未操作、錯誤位置、四個固定月相不能誤過數值關。50°、約2.05能通過，回饋說明位置與潮差的因果，提供重試／下一關／退出／重玩。
- 學習步驟、參數、已通過關卡改存 localStorage；不可用時回退 sessionStorage。不新增帳號、後端或跨裝置同步。

## 實看證據

六尺寸各0、45、90、180、270度共30張 `*-water-*.png`；六尺寸 `*-mission.png`，手機另有場景和任務切換畫面。考核頁所有尺寸側欄 overflow=0，頁寬高均符合 viewport。原尺寸圖與 contact 縮圖均人工檢查。批次擷取發現兩張靜止畫面未帶出 canvas；為隨需渲染保留 drawing buffer，避免已繪完的 WebGL 內容被清空後截成黑圖。重拍並檢查完整場景及瀏覽器日誌，不以黑圖作驗收。

本輪重新打開使用者 X 連結，按播放後實看約8.2秒處的連續海面、光感與同步面板。參考仍比本版有較亮、精緻的地表／海面質感；本版改用較柔和的吸收光與細波紋，沒有宣稱視覺已完全相同。X素材未加入應用。比較圖 `before-after.jpg` 只包含我們自己的修正前後實際截圖。

`before-2359d21.jpg` 和 `after-water-mission-1280.png` 為相同1280×720、新月0°、預設立體鏡頭；後者也顯示新考核。
