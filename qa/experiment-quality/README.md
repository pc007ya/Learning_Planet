本批次只改新 3D 六模組，原首頁、14 個入口與原模組未更動。既有潮汐原始碼與頁面保留；地月的 classic.html 使用原引擎的獨立 legacy entry，避免共用引擎升級覆寫舊體驗。此批次僅供審查，不授權部署。

## 實作前的參考與驗收準則

實際查看官方作品：
- https://lab.tongjiang.app/accel-force-step （車、量測、控制變因、多次操作）
- https://lab.tongjiang.app/plasmolysis-step （水路、時間、狀態與讀數同步）
- https://lab.tongjiang.app/water-cycle-step （海陸氣與回流）
- https://lab.tongjiang.app/earth-motion-step （地表、日照、地面與太空觀測）

磁鐵／浮力／國小植物沒有完全同題的官方範例，因此比較的是材質、可辨識模型、連續操作、讀數、引導與實作深度，不冒稱逐項一對一。參考 CC BY-NC 4.0；本批次未複製其程式或資產。參考截圖僅留本機研究，不隨 PR 公開。

## 模組的真實改變

- 浮力：水槽、空心船／潛艇可辨識；球冠、盒、橫膠囊、船殼幾何排水量，重量與浮力同尺度箭頭；同重改體積、淡海水、中性浮力；真正靜止後才留紀錄。
- 磁鐵：有限磁極示意場、線與指南針、可拖動磁鐵真吸斥、獨立鐵／塑膠試驗；有效移動與距離考核；相對值不假裝校準磁場。
- 地月：沿用專案合法地表與月面貼圖，受光、晨昏線、23.4°地軸、連續月相、地面高度對照；48px月球拖曳，滿月夜面操作考核；潮汐入口保留。
- 植物：有分枝根系、根莖葉水路、彎曲葉與葉脈、葉片失水／恢復；水／光／土／二氧化碳條件，固定其他條件比較；時間為加速示意。
- 天氣：蒸發、上升冷卻、露點凝結、雲滴長大、降雨、地表與地下回流；保存總水量、凝結非立即降雨；氣團實際拖動。
- 力與運動：車輪、推桿、配重、導軌、光電門、緩衝區，推力／摩擦／淨力；沒有任意速度封頂，放手仍前進／摩擦停止；4m實際計時與控制變因配對，多次紀錄不倒扣已獲進度。

## 證據與限制

各子資料夾的 ACCEPTANCE／MANUAL-QA／IMPLEMENTATION 與 JSON 記錄實際操作和尺寸結果；最終狀態以精確 commit 的 CI 與修正後截圖為準，不把舊版通過套到新版。自動化只補充人工看圖，不能證明與參考全面同等。

仍有範圍內明示的模型限制：非流體求解、磁力相對示意、植物加速非真實生長預報、天氣封閉水箱非真實天氣預測、地月固定理想季節與地心方向不含視差／折射、力學一維滑動摩擦。未測實體 iOS Safari、低階 GPU／真機效能、跨裝置帳號同步；本機進度不宣稱雲端同步。
