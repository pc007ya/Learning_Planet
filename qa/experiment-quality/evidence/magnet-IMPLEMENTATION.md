# 磁鐵候選：實作與實際驗收記錄

本模組由 `magnet.ts`、`magnet-model.ts` 和 `tests/magnet-quality.test.ts` 組成。此檔記錄已實際執行的操作與看圖驗收，以及模型限制；不代表與參考作品全面同等。

## 原版落差與已實作變化

| 原版 | 候選版實作 | 驗收判準 |
|---|---|---|
| 平移／翻轉方塊與縮放浮球 | 金屬夾具固定左磁鐵、右磁鐵在導軌上自由吸斥運動 | 異極放手靠近、同極放手退開，位置與相對力數值同步 |
| 無實際磁場方向 | 兩個有限長磁偶極外場疊加；積分磁力線、方向箭頭、八支指南針 | 翻極後場線與指南針改向；N 外流、S 流入，不用裝飾球縮放充當磁場 |
| 材料只切顯示 | 前方獨立小試驗台；鐵釘向測試磁鐵移動，塑膠維持位置 | 兩材料相同起點、相同條件，鐵釘無固定 N/S 標記 |
| 按過按鈕便算完成 | 相吸、相斥需要實際位移；材料需要實際觀察時間 | 考核必須同極、操作介入並實際退開，不是答案選擇 |
| 圓柱／方塊缺少辨識 | 圓角雙色磁鐵、N/S 印字、金屬夾具／軌道／螺栓、可辨識鐵釘、雙色指南針 | 1024×600 和手機仍可認出主要元件，沒有被裁切或文字遮擋 |

## 共用頁面接線

- `createMagnet(stage): World`，保留 `pole / distance / material` 原控制 IDs 與選項，新增 `field=on/off`。
- `metrics` 提供磁極間距、相對磁力與方向；`readout` 隨物理位置更新。
- `steps` 三段、`modelNote`、`sourceLinks`、`challenge/checkChallenge`、`demo`、`setPlaying`、`snapshot/restore` 均已提供。
- 命中可移動右磁鐵／滑座才開始 pointer drag；空白區仍交給共享相機。拖曳時停用 OrbitControls，釋放後觀察吸斥。
- 三個可存取動態 DOM 標註：固定磁鐵、拖磁鐵、材料試驗，由共用 Stage 排位。
- DOM QA 讀值：`#ep-scene` 的 `data-magnet-x / gap / force / pole / field / material / material-x / motion`。

## 科學與素材來源

- [OpenStax：磁場、磁力線與力](https://openstax.org/books/physics/pages/20-1-magnetic-fields-field-lines-and-force)
- [OpenStax：鐵磁性、誘發磁化](https://openstax.org/books/college-physics-2e/pages/22-2-ferromagnets-and-electromagnets)
- 參考品質項目：官方 README 指向 [電流的磁場](https://lab.tongjiang.app/current-field-step)。它是高中電流磁場課，不是一對一的小學棒磁鐵課。此處只比較立體辨識、場方向、操作聯動與教學深度。已在自己的獨立 IAB 分頁實看其 1280×720 畫面，本機內部截圖為 `reference-current-field-1280x720.png`（參考畫面不納入公開交付／部署）；參考包含透明玻璃板、投影陰影、電路、即時數值曲線及九段操作路徑。本模組採不同的棒磁鐵主題，不能稱為同題或宣稱全面同等。
- 場景、磁鐵、字面 CanvasTexture、指南針、場線、鐵釘均為本次程序建立，沒有複製參考資產。three.js 與其 RoundedBoxGeometry 使用專案既有依賴。

## 模型限制（亦提供給頁面可見說明）

- 有限長磁偶極的數學外場，非真實磁鐵形狀與材料的工程預測；雙極數學表示不表示存在單獨磁荷。
- 相對力、場線、速度、尺寸有教學放大，沒有虛構牛頓／特斯拉。
- 場線表示方向；固定線數不能當作精準場強刻度，圖外仍有磁場。
- 導軌使用阻尼、最小間距限制與近距離平滑，不模擬真實碰撞、磁滯或釘子的真實磁化時間。主導軌的兩磁鐵場與前方材料小試驗採獨立示意，未計算兩試驗區之間的交互磁場。
- 左磁鐵由夾具固定，仍受大小相同、方向相反的模型力，兩側箭頭同步。

### 視覺差異與未宣稱項

- 參考是高中電流／線圈場，具有 μT 計算與較多步驟；本頁為國小棒磁鐵、相對力與有限長偶極場的教學模型。未校準真實磁鐵材料、磁滯、任意姿態轉矩或地磁場，不能把此候選說成等同其全部物理能力。
- 顯示指南針只指向本模型場；已在頁面 modelNote 明示未疊加地磁場。
- 最新候選真同極操作：x0.55 放手退開至 4.001，考核 `passed=true`；暫停後刷新，x4.002，仍可核實 `passed=true`，見 `360x780-challenge-pass-final.png`。
- 考核位移門檻與可見目標一致為 0.15 格，含二進位小數誤差容忍；2.35 格近距離仍可通過真操作，2.19/6.51 格越界拒絕。已加入純函式邊界測試。
- 桌面預設有實體 N/S 印字；窄手機用錨定磁極的固定螢幕大小 N/S glyph 提高辨識。已實看確認桌面只顯示實體刻字，手機只有一組 glyph；兩主磁鐵有不可見、noFit、無 raycast 的標註保護盒，名稱不再遮住 N/S。
- 參考場景與本頁風格不同，不把測試通過當作視覺同等。現有控制是沿導軌連續距離與兩種翻極、固定材料試驗，沒有完整自由磁鐵六自由度碰撞或校準實驗儀器。
