# 植物候選：實作與待畫面驗收

此文件記錄程式與模型檢查，不將單元測試當作畫面驗收。尚未宣稱與參考同等，未部署。

## 參考與來源

- 官方 catalog：植物細胞吸水與失水 https://lab.tongjiang.app/c/plasmolysis-step/ 。題材並非盆栽一對一；借鏡多尺度剖面、水分變化因果與操作考核的品質要求，未複製其程式或資產。代理的 web renderer 讀此互動頁失敗，實際畫面由 root 集中檢查。
- OSU Extension，Environmental factors affecting plant growth（機構一手園藝教材）：https://extension.oregonstate.edu/catalog/em-9903-environmental-factors-affecting-plant-growth 。核對光照存在上限、缺水與膨壓、蒸散、根部供水與養分限制；未複製圖片。
- Rice University/OpenStax Biology 2e, 8.1：https://openstax.org/books/biology-2e/pages/8-1-overview-of-photosynthesis 。核對光、水、二氧化碳與糖的概念；未複製內容圖。
- 所有陶盆、土壤、葉面/葉脈、根系、水壺、粒子均由本模組程序建立，沒有新增第三方資產。

## 已實作

- 陶盆與土壤有獨立曲面／紋理；葉片為 22×8 曲面網格，具有中脈及雙側葉脈，非幾個壓扁球體。第七天另展出幼葉。
- 整株／根與莖剖面。剖面陶盆和土層透明，可追蹤分枝根、莖中運輸與到葉片的水路；葉上有蒸散追蹤符號。
- 控制條件：少/適量/強光，缺水/適量/積水，土壤養分，二氧化碳供應，示意第1/7天。保留舊 light/water/days ID 與原值。
- 活水分指數具時間漸近變化；缺水後葉片依膨壓下垂，澆水後逐漸恢復。積水抑制根部供氧；光太強在此課堂條件增加水分需求，不教「越多越好」。
- 命中水壺才能拖動，釋放在盆土上方才澆水；未命中讓共用相機操控。圖卡提供鍵盤/觸控替代。
- metrics：葉片水分、光合作用、蒸散相對指數，及示意天數。snapshot 含條件、時間、水分、觀察值，供固定條件比較與還原。
- 三項觀察任務只在實際模型條件成立時完成。救回植物挑戰要求先觀察低水分，再恢復至70並保持適量水/光、養分及正常空氣；只點過選項不能通過。
- 示範從缺水到適量水，不替學生完成觀察或救回挑戰。播放暫停及離開釋放資源已接 World/Stage 介面。

## 科學模型限制

所有0–100輸出為無單位的相對示意指數，不是測得流量、氣孔導度或實測光合速率。第7天的幾何不是品種或生長預測。粒子是追蹤符號，水氣本身看不見。未模擬溫度、濕度、病害、物種差異、真實土壤水勢或糖分輸送。土壤提供水與礦物質，糖主要由光合作用製造；不把土壤當成植物食物。

## 模型測試（已跑）

`npx vitest run tests/plants-quality.test.ts`：8項通過，涵蓋固定其他條件的光照比較、水/CO2限制、強光/積水不保證健康、缺水/恢復漸近與步長一致、挑戰必須真實狀態、日數不偷偷改水分物理；另直接建立 World 驗證示範/暫停不給挑戰、完整缺水恢復、固定條件比較與快照還原。

## root 整合後必實看

1. 1024×600 / 1024×768 / 1280×720：整株、根莖剖面、缺水、恢復、看圖題，不能依程式推測合格。
2. 390×844 / 360×780：注音開關，水壺命中區與相機拖曳不衝突；圖卡切換不能被裁掉。
3. 固定水/土壤/空氣/日數，比較適量光和少光，保留條件＋時間＋光合/葉水分讀數。
4. 積水與缺水均不能救回挑戰；缺水觀察→適量水→播放至水分70以上→檢查才通過。
5. 暫停時粒子與恢復停止，條件改動仍更新文字；離開時解除拖曳與釋放程序紋理。
6. 語音、動態注音、題目往返與快照還原由共用 app 驗證。
