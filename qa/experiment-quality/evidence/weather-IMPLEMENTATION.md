# 天氣與水循環：實作與待驗收

本模組為原創程序 3D 幾何／材質／雲體貼圖，沒有複製銅匠實驗室或第三方圖像／程式。

## 已實作

- `weather.ts`：獨立海岸山地剖面、不同土層、河流、湖泊、地下水回流，程序柔邊雲體與放大雲滴；水氣只以明示的箭頭表示路徑，沒有把可見粒子當成水氣分子。
- 原三組條件 `sun(strong/weak)`、`humidity(wet/dry)`、`air(cool/warm)` 保留。金色空氣團可命中拖曳，上升對應連續冷卻；操作後讀數由共享 UI 更新。
- 雲滴、雨絲、地表／地下回流水滴分開，從模型狀態驅動可見變化，不是 wet+cool 直接切下雨。
- 四步觀察、三個有實際觀察門檻的任務、因果操作考核、原看圖題語義、示範、暫停、snapshot/restore。
- 底層 1m³ 空氣盒採 Tetens 飽和曲線與理想氣體水氣密度。雲滴成長是教學尺度的有限時間 bulk 參數，並非真實雲滴尺寸譜。
- 水面→水氣→雲水→降雨→地表／地下儲量→水面各步保水量守恆。兩種水氣按鈕透過水面儲量重新設定空氣盒的水氣，不創造水量。

## 科學限制（頁面需可見）

這是加速單空氣盒示意，不是天氣預報。用外加冷卻條件表示空氣上升，未解氣壓、風場、對流或潛熱反饋。假設存在凝結核。僅示範暖雲碰併成雨，不模擬冰晶。空間、雲／雨滴與回流水量尺度誇張，雨量不可解讀成實際 mm/h。

- NOAA *Atmospheric Collisions*: https://www.noaa.gov/jetstream/global/learning-lesson-atmospheric-collisions
  - 碰撞與合併使雲滴成長到可降雨。

  - 凝結快速產生雲滴，降水還需要後續成長過程。

## root 整合後實際 QA 清單（尚未宣稱通過）

1. `weather.ts` 已接線並實際載入，桌面、1024×600、1024×768、1280×720、360×780、390×844 检查。
2. 暖空氣 5 秒：可見輸送箭頭但無雲／雨；加熱讀數變化可追蹤。
3. 選變冷或直接拖高空氣團：溫度下降、RH 上升、先雲滴成形；頭幾秒沒有雨。
4. 繼續觀察：放大雲滴逐漸聚合、雲滴成長讀數增加、達門檻才有雨絲，接著地表和地下回流。
5. 變乾暖：雲與雨逐漸變化，不能一按立即切空；比較紀錄保留固定條件與讀數。
6. 每個主要視角檢查雲體深度、地形、標註遮擋和對比。金色可拖空氣團命中區需 ≥44 CSS px，測手機實際拖曳；非實體 Safari 測試必須明示。
7. 暫停停止模型與動畫，題目來回不重設，重設回初始狀態，示範不得直接替代孩子操作考核。
8. Logo＋ㄅ、動態題目／回饋／讀數字詞的注音；「飽和」和讀 ㄏㄜˊ，不應套連接詞讀音。
