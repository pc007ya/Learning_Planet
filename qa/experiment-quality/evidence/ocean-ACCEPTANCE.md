# 海洋浮力新版 — 實作與待實看驗收

## 實作範圍

- `src/experiment-planets/ocean.ts`：原創程序 3D 水槽、金屬框／透明玻璃、細波紋水面、六種可辨識獨立寶物，材質紋理均由本程式產生，沒有搬用銅匠或未知授權素材。
- `ocean-model.ts`：水平方向的球／橢球切面、盒形、膠囊體、梯形密封船殼之浸沒體積與浮力；主外形統一 0.006 場景體積／cm³，附屬零件不計排水。
- `tests/ocean-quality.test.ts`：七項模型與因果考核測試。
- 舊控制 IDs、五項探索任務、潛艇方向操作和看圖題答案索引 1 保留，供原有回歸驗證接續使用。

## 從參考轉成可驗收項

參考庫沒有一對一的浮力小學課。以其「立體世界、即時讀數、分步問題、模型狀態考核」為品質基準，沒有聲稱逐題相同，也沒有借用其 CC BY-NC 素材。

| 需求 | 本輪實作 | 實看／操作驗收方式 |
|---|---|---|
| 真正可辨識物件 | 木紋木塊、岩紋橢球石、分色充氣球、刻線密度球、膠囊潛艇、空心梯形船 | 六件依序選取，應無重疊殘件、材質明確、船艙可辨識 |
| 可操作模型 | 命中寶物的 raycast 拖動 + 48px DOM 手把；垂直拖曳後釋放自由浮沉，空白留給 orbit | 觸控／滑鼠拖寶物與空白各一次，兩種操作互不搶事件；手把方向鍵移動、Space／Enter 釋放 |
| 質量與體積分離 | 同一主外形改體積按立方根縮放；改重量不改尺寸 | 密度球、淡水、100g：70cm³ 沉底；130cm³ 浮起，最後 Fb≈W |
| 水種對比 | 淡水 1.000g/cm³、海水 1.025g/cm³ | 同一密度球 100g／100cm³，淡水中性，海水略浮，浸沒比例下降 |
| 讀數真正聯動 | 重力、浮力、排水量、浸沒比例四讀數、青色上箭頭／橘色下箭頭 | 拖到水面上方 Fb=0；完全浸沒後 Fb不因更深而繼續增加；沉底 Fb仍非0 |
| 分步引導 | 猜浮沉、同重量改體積、同物件換水、潛艇壓載 | 引導步驟會放好對應物件，仍可自由改條件 |
| 真操作考核 | 先縮小密度球沉底並留下 settled trial，再放大到真正受力平衡 | 未實做或球仍在運動時不能通關，不能僅點正確選項 |
| 比較證據 | `snapshot.trials` 保存最多24筆實際穩定狀態，含質量、體積、水密度、浸沒比例、Fb/W | 共用紀錄面板可呈現前後比較；僅當自由浮沉穩定後記錄 |

## 模型邊界與未測

- 只模擬理想靜水、垂直浮沉與黏滯阻尼。不是流體解算，不模擬波浪、渦流、船艙進水；船艙視為密封。
- 潛艇只計主壓力殼排水，附屬窗框、尾翼／潛望鏡不計。船主外殼按梯形積分。
- 兩支力箭頭同次共用線性自動縮尺；跨次必須看牛頓讀數，不能只比箭長。沉底有支持力，不能把 `Fb-W` 誤稱完整合力。
- 本子任務沒有獨自 build 共用輸出、沒有開啟共享瀏覽器改 viewport，待根任務整合後執行桌面／平板／手機實際畫面與操作驗收。不能據單測宣稱視覺已達參考水準。
- 實體 iOS Safari、低階 GPU 尚未測。
