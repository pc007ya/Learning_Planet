# 英文原創延伸試教

從主站英文頁「原創48課」開啟。既有英文遊戲與獎勵不變。傳統列表與3D節點地圖共用同一套本機學習者進度；不支援跨分頁寫入鎖時採唯讀。關閉、切人或登出會釋放地圖、語音與鎖。

48課480題、312個拼寫任務、24個日常主題詞義檢查。包含280不同字形，並非300詞能力已達標。課程為原創延伸，出版社冊別/學期對齊與教師驗收待核；口說自評不等於發音評分。圖片僅教學用途，有些需搭配文字語境，不作獨立看圖測驗。

本機進度以主站currentId區隔，未接Firebase同步或XP/coins。嵌入頁要求一次性同源host契約；不能從URL指定學生，也不會退回示範學習者。iframe是UI隔離，不是同源安全邊界。

儲存v4與舊候選隔離，不刪除或自動搬移舊資料。正式入口仍須實機驗收發聲、WebGL、觸控及無障礙；CPU測試不代替這些驗收。
