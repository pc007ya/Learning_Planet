# 生活與自然單元練習候選整合

本模組擴充自然星球：一、二年級為生活課程，三至六年級為自然科學。康軒、南一各按年級和學期分開，合計110單元、24個版本／年級／學期組合。

## 發布開關、預覽與既有資料

- 部署已獲授權，仍待最終檢查與核實發布，沒有部署成功證據。`science-rollout.js` 的 `SCIENCE_CURRICULUM_RELEASED` 預設為 `true`，主站與模組共用；設為 `false` 可明確回退，網址參數不能覆寫。
- 獨立預覽：以本機HTTP服務開啟 `science-curriculum-preview.html`。
- 原網站登入後可由自然星球進入，不再要求 localhost 或 `?scienceCandidate=1`。先前瀏覽器證據來自本機候選入口，不能代替正式站發布後驗證。現有23個自然項目的ID、原題庫、計分與實驗均保留。
- 紀錄使用獨立 localStorage key `lp-science-curriculum-candidate-v2:<learner>`；不同學生不混用。候選紀錄不雲端同步、不灌入正式熟練度。
- 相容的10題未完成回合可續答；資料版本改變或舊3／5題回合會封存保留，不覆寫原答題。實作規準改變時保留舊自評與原筆記，新規準須重新自評。
- 同瀏覽器、同來源、同學生的編輯視窗由原生 Web Locks 保護，第二分頁暫不抽題。沒有分頁鎖支援時明示並停止寫入。格式損壞、容量不足或過期覆寫時保留原資料。

## 教學與來源界線

- 每單元至少30道原創核心候選題，每回固定10題，無計時要求。按學生、單元保存有限題池，先抽完本輪才重置；跨輪邊界的同回10題仍不重複。
- 原1152題與164筆任務原文保留。已辨識近重或錯置題以 question_policy 排除新核心回合，必要文字修正由投影套用；舊答題快照不重算或改寫。
- 每回合開始前先保存10題與題池預留紀錄，重整會續答，不重新洗題。已完成或封存的舊紀錄納入遷移；這不是跨裝置或雲端同步的永久不重複保證。
- 練習面板採原數學介面的結構和既有素材：白色工具列、左側引導角色、中間題目與四選項、右側提交、下方本題分析。先選擇再提交，不因點選直接判分。
- 自然3D地圖是獨立入口，與直接單元清單共用同一題庫和紀錄。詳細資料數目見 docs/science-curriculum/question-bank-summary.json。
- 實作涵蓋觀察、合作、表達、創作、跨日記錄及證據修正。自評與答題分數都不是能力已達成的證明。
- 14個生活補充設計共享於28個兩版入口，保留同一任務ID與實作紀錄，不偽裝成28個獨立設計。
- 課綱碼是設計對照，教師正式審定、兒童試測及實際作品／歷程證據仍需另行取得。
- 版本來源以115學年度官方簡介及學校採用計畫為主，不聲稱已驗證每本ISBN或出版社每一頁內容。完整來源見 `docs/science-curriculum/source-coverage.md`。
- 南一二下「色彩很特別」的114計畫延伸資料保留，但不納入115核心回合。南一五下聲音單元的樂器製作子活動保留原ID，不任意重編已存在的題目。
- 所有題目／任務維持 `candidate`。引擎預設拒絕候選題，由已啟用的練習 UI 明確允許使用；發布開關不代表內容已通過教師審定。

## 可重現檢查

在專案根目錄：

```sh
npm ci
# 只執行生活／自然課程檢查（含 DOM 流程）。
npm run test:science-curriculum
# 自然地圖、動物巡遊、碰撞及真實練習橋接（GPU另需實測）。
npm run test:nature-planet
# 常規 CI：包含上述課程檢查與所有既有科目的檢查及建置。
npm run check
```

DOM 檢查使用根目錄鎖定版本的 `linkedom@0.18.12`，不依賴 QA 目錄的私有安裝路徑。Playwright 只供選用的本機畫面驗收，不加入根目錄依賴或常規 CI。

DOM 模擬檢查不等於瀏覽器畫面驗收。真正瀏覽器需在可用的本機環境安裝 QA 依賴並啟動 HTTP 服務，另執行：

```sh
npm ci --prefix qa/science-curriculum --ignore-scripts
python -m http.server 8765 --bind 127.0.0.1
# 另一個終端，使用已授權安裝的Chromium；或先在授權環境安裝Playwright官方瀏覽器。
CHROMIUM_PATH=/path/to/chromium node qa/science-curriculum/browser-check.mjs
```

不要為了跑測試停用系統安全設定或繞過發布開關。若瀏覽器環境無法執行，應記錄未測項目。

正式 Pages 與 Firebase Hosting 打包排除 `docs/science-curriculum/`、`qa/science-curriculum/` 、`science-curriculum-preview.html` 及 `nature-planet-preview.html`；課程 runtime 與 data 維持可打包。原始本機 QA 報告由 `qa/science-curriculum/.gitignore` 排除，不應提交或公開。公開整理後的驗收摘要放在 `docs/science-curriculum/`。這些排除不代表已部署或已通過候選版本的遠端 CI。

## 朗讀能力與失敗處理

朗讀使用瀏覽器原生zh-TW語音，不新增外部TTS。環境需具備可用的語音合成服務；支援API不代表能出聲。失敗訊息只更新被點擊按鈕旁的狀態，不清除尚未加入的觀察草稿、日期或展開區塊。

本次最小原生語音與課程模組在同一Chromium環境均回報synthesis-failed，而Web Audio與本機WAV的數位播放管線正常；沒有成功中文聽測。詳見[原因與修正](../../docs/science-curriculum/audio-diagnosis.md)。
