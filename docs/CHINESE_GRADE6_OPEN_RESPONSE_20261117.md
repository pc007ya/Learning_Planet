# 自行摘要／提出證據：開放式活動

## 已實作

既有12課各加獨立「自行摘要與提出證據」入口，選擇題與原文不變。學生先讀原文，再寫：

1. 用自己話寫2–3句摘要（詩歌改為畫面、變化與理解）。句數僅建議，不自動扣分。
2. 一個本文可支持的看法。
3. 具體原句／細節及段落位置。
4. 證據為何支持看法，並保留未知之處。

四項自評只幫學生檢視「自己的話、具體證據、推理連結、不過度推論」。不計時、不自動判對錯、無AI評分、無精熟判定、無發獎。所有畫面與輸出明示未經教師評閱；沒有聲稱任何教師已看過。教師／家長可由學生自行交付文字稿後，按上述重點給回饋，本功能不替人評閱或傳送。

## 保存方式及隱私

獨立頁沒有可用的可信學習者身份，不能在共用瀏覽器中自動保存並展示上一位孩子的草稿。因此採取明確下載／匯入，而不是localStorage或雲端：

- 下載本課JSON草稿，可下次在相同課程匯入續寫。
- 下載純文字稿供自行交給教師／家長檢視。下載不等於送交，也不等於已評閱。
- JSON限本課ID與固定schema，文字各最多2000字元、檔案最大64KB。未知「分數／教師通過」metadata不採用。
- 不收姓名，不用網路傳送輸入內容，不把草稿放入共用瀏覽器持久儲存。不防止同裝置持有人開啟已下載檔案，因此提醒不填私人資料，保存者自行管理下載檔案。
- 產生下載後提醒使用者確認檔案已保存，不宣稱作業系統已實際寫檔成功。若下載拋錯，頁面內容保留且仍標未保存。
- 未下載修改離開時提醒；匯入覆蓋前確認。背景匯入若遇到新輸入／退出／換課，不得蓋掉新草稿或重現舊畫面。

## 驗證範圍

新增11項寫作回歸，連同13項既有閱讀回歸共24項通過：草稿往返、同課隔離、格式／容量驗證、文字HTML安全、不信任外來評閱狀態、下載失敗保留、未存退出確認、異步匯入退出／新輸入隔離、空白新課、無網路／持久儲存／假評分。typecheck、diff check通過。

目前是可操作、自評及可交付的寫作練習，**不是已完成教師評閱的能力證明**。未完成真瀏覽器下載互動、手機鍵盤、學生試用驗收，不把DOM測試等同這些驗收。下載後需由使用者確認檔案留存；瀏覽器不支援或禁止下載時可直接複製文字。

獨立程式審核找到頁首連結開新頁會錯誤清除當前草稿監聽的問題，已修正並新增Ctrl/Cmd/Shift/Alt/中鍵/target=_blank逐項回歸，保留原頁草稿與dirty保護。另明示beforeunload在手機／瀏覽器被關閉時不保證觸發，不能承諾所有離開方式都提示，重要內容應先下載並確認保存。
