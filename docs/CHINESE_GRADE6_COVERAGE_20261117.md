# 六年級原創閱讀：覆蓋盤點與缺漏

## 判讀原則

盤點基準是前4批11課110道選擇題，不是36筆出版社來源索引。索引沒有課文、核定學習目標或題目，完全不計入能力內容覆蓋。以下是設計端的內容盤點，不是學生達成率、官方審定、逐出版社對齊或完整課程聲明，不計算「完成百分比」。

規劃參照國教院公開[國語文課程手冊](https://www.naer.edu.tw/upload/1/16/doc/2080/%E8%AA%9E%E6%96%87%E9%A0%98%E5%9F%9F-%E5%9C%8B%E8%AA%9E%E6%96%87%E8%AA%B2%E7%A8%8B%E6%89%8B%E5%86%8A%28%E5%AE%9A%E7%A8%BF%E7%89%88%29.pdf)第三學習階段的閱讀相關說明（查閱2026-11-17）：5-Ⅲ-4/5關注事實判斷與議論，5-Ⅲ-6/7涉及摘要與評述，5-Ⅲ-8/9涉及推論及目的導向策略，5-Ⅲ-12涉及資料蒐集判讀；另有朗讀與寫作要求。這些參照只用來提醒範圍，不代表選擇題已完成該項表現，也未把第三階段全部要求等同六年級單一年級的固定課單。

## 11課實際覆蓋

| 向度 | 已有內容（ID省略共同前綴 zh-original-g6-） | 明確限制 |
| --- | --- | --- |
| 擷取訊息、條件、時序 | evidence、structure、announcement、schedule、interview | 多數有直接句子可找，不能代表長文閱讀或獨立策略熟練 |
| 推論、證據範圍、事實與觀點 | evidence、viewpoint、compare、argument、perspective | 題數偏多且有重複概念；不應再以換情境大量增加同質題 |
| 主旨、摘要辨識、篇章組織 | structure、narrative、poem、interview、perspective | 都是選出現成答案，尚未要求自行寫摘要、組織證據或說明理由 |
| 敘事人物、觀點與情緒 | narrative、perspective | 只短篇單一事件，缺較長文本的發展與複雜人物比較 |
| 詩意、修辭與語境 | poem、narrative | 現代小詩與常見比喻/擬人為主；語詞多義、語境推詞、古典詩文未形成獨立教學序列 |
| 議論與不同需求 | viewpoint、argument、interview | 能辨理由與限制，不等於學生可自行提出或修訂論證 |
| 應用文本、跨文本整合 | announcement、compare、schedule、interview、perspective | 行程以文字段落呈現，尚非實際圖表/圖像多模態操作 |
| 數位來源與閱讀策略 | 零散的查證/追問題 | 缺發布者、完整來源、日期更新、矛盾資訊追查的集中練習；缺真正自己搜尋和引用資料 |
| 朗讀、聆聽、口語討論、寫作 | 無可驗證任務 | 文字選擇題不測流暢度、聲調、口語互動或書寫，不得列為達成 |

## 本批只補一個可驗證缺項

新增「查來源，也看更新」一課10題（source-check），以全原創虛構網頁/轉傳/查核紀錄補：

1. 先確立閱讀目的再定位資料，仍讀完整條件。
2. 區分發布者、完整頁面、更新時間與缺來源截圖。
3. 避免「較晚一定正確」或「主辦永遠不會變」的單一判準。
4. 遇到矛盾回到可核對管道；沒有回覆就保留待查，不代寫查核結果。
5. 轉述時保留來源、時間與不確定性。

本批後合計12課120題，仍每課10題，不新增出版社映射。這只是來源判讀的情境辨識練習，**不代表已完成真實網路蒐集、查證或引用的實作能力**。

## 下一階段必要工作（優先於再湊課數）

1. **自行摘要與證據表達**：加入不自動判對錯的短答／紙筆任務、明確規準與教師回饋，先確認學習者隱私與儲存政策。現有選擇題解析可作示範，不直接拿答對率當寫作能力。
2. **語境詞義與篇章銜接**：用一份有足夠上下文的原創說明短文，針對多義詞、指代、承接、同義改寫與刪修建立少量可驗題，避免再做「哪個是事實」同質題。
3. **可讀圖表與長文**：先做真正可及性的表格／圖說呈現與足量閱讀時間，再測跨模態整合；不能只在標題寫「圖表」卻僅呈現流水文字。
4. **古典詩文／語文基礎**：先查可用且可靠的文本、註解、字音來源與版權，另行設計，不以仿古新作冒稱古典教材。
5. **朗讀與討論**：需語音實聽、師生/同伴回饋方式，不以播放按鈕、TTS可載入或一輪選擇題當驗收。

以上為優先序建議，尚未實作部分不能列入發布成果；需依實際教學需求再選，不以索引數量或固定總課數催生內容。
