# 完整教學傳動鏈

此版本補齊動力傳遞拓樸，不是品牌石英機芯、製造圖或碰撞物理模擬。齒廓是簡化示意；馬達以連續旋轉表示，不模擬石英電路脈衝及電磁場。

馬達轉子與 12T 小齒輪共軸 → 36T／同軸12T → 48T／同軸12T → 60T／同軸長分針與藍色12T → 金色36T／同軸10T → 40T／中空軸套 → 短時針。

前三組外嚙合減速比 3×4×5＝60，後兩組 3×4＝12；總比 720。各嚙合齒輪使用同模數、同平面及分度圓半徑和的中心距。同軸輪以明示軸相接。

`clockDrive` 是唯一前級角度來源；`clockTrain` 由其分針輸出繼續推導。正常模式等效 RPM 是 1 → 1/3 → 1/12 → 1/60 → 1/180 → 1/720。60 倍播放是 60 → 20 → 5 → 1 → 1/3 → 1/12。實際播放時間 60 秒對應時鐘一小時。

面板分馬達、指針兩個圖示頁籤，整併到倍率與朗讀的同一列；移除面板放大，保留收折。點1×或60×直接以該速度播放，運轉中切換保留進度；60×一分鐘走完一小時，1×需真實一小時。底部播放鍵保留所選速度，可暫停。綠色標記前級，藍／金色標記原有指針輪系。原有拆卸、旋轉、透明刻度盤及零件表保留。
