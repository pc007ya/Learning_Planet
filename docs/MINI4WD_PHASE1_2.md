# 電池四驅車研究所：第 1、2 階段

日期：2026-09-08。新增實驗，不替換回力車、時鐘、浮力或方塊。

## 實作範圍

- 主站 `exp-mini4wd` 入口；獨立檢閱頁 `mini4wd-lab.html`。
- 同一原創 3D 車輛模型共用於原理、BOM、組裝、改裝及賽道。
- 18 組教學零件，四個輪圈、四條輪胎分別安裝；檢查先後依賴及反向拆卸。
- 點選與拖曳安裝、旋轉、放大、透視與爆炸圖；零件圖卡由同一 3D 模型即時渲染，沒有底圖裁切碎片。
- 原理四步、共用 SceneNarration、重聽、三題看圖挑戰、試跑紀錄；在頁籤之間保留配置與組裝狀態。
- 齒比 3.5 / 4 / 5、抓地胎／硬胎、輪徑 26 / 30 mm、兩種車殼、兩種配重與三種車色。車色不影響性能。
- 閉合軌道、護欄導輪接觸、跳台、空中重力、落地損失、三圈計時、車頭／追車視角、減少晃動、馬達與風聲。
- 單車試跑與本機雙車碰撞測試。橘車是標準配置的測試車，不冒充線上玩家。
- 獨立兩客戶端伺服器協定樣板及實際雙 SSE 客戶端測試，不是四人正式房間。

## 物理模型邊界

`mini4wd-physics.ts` 使用 1 模型單位 = 5 cm、秒與 kg。固定步長 1/240 秒；馬達採線性扭力／轉速近似，輪胎採側向摩擦上限，四個導輪接觸對平面剛體施加線性與角動量。垂直方向採重力與落地耗能。速度單位顯示為模型換算 km/h。

車身不按樣條直接修改位置；軌道中心線只用於生成幾何、求護欄距離與累積有方向的圈數。車對車採兩圓盤膠囊代理。外觀網格不是精密碰撞網格。未做完整 6 自由度翻滾、輪胎變形、齒面碰撞、電池放電曲線或氣動計算；外殼僅透過設定重量影響性能，不虛構氣動效果。

BOM 是教學分組，不是品牌維修圖／採購料號。省略部分螺絲、軸承與齒輪細節，不可用作實體下單清單。

## 驗證與執行

```sh
npm ci
npm run check
node scripts/test-mini4wd-sync.mjs
```

同步樣板需 Node 22.18+ 或 Node 24；以 `node scripts/mini4wd-sync-server.mjs` 啟動，僅綁定 loopback，預設 4381。兩個客戶端各 `POST /join` 取得暫時 token，設定後 `POST /ready`，兩端 ready 才啟動；`GET /events` 是 30 Hz 權威快照。客戶端不能上傳座標、圈數或名次。`/setup` 在比賽中鎖住。不包含正式登入、重連、TLS、網路延遲補償或四人房間，勿直接公開部署此服務。

完整 `npm run check` 通過：27 個測試檔、444 項測試，包含新增的 9 項行為測試，並完成 TypeScript 與兩組正式建置。

新增行為測試涵蓋三圈、落地、護欄碰撞、斷電靜止、顏色不影響性能、齒比差異、動量與能量、賽道一致性、高速護欄及組裝依賴。同步測試以兩條獨立 HTTP SSE 連線比對共同 tick 的完整快照；本次 12 組相符，同時驗證滿房、無效 token、非法配置與賽中設定鎖定。
