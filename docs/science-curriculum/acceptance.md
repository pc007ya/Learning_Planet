## 回合、介面與資料保護

- 每回固定10題，沒有計時。數學式練習面板沿用既有素材與結構，先選答案再提交，判分後由使用者按下一題；樣式限定於自身介面。
- 同一學生、同一單元、同一瀏覽器來源使用有限題池，跨回合先取完一輪才重置；跨輪邊界的同回10題仍不重複。這不是無限回合、跨裝置或雲端同步的永久不重複保證。
- 開始回合前保存10題與題池預留紀錄，重整續答。Web Locks 保護同一學生的編輯分頁，第二分頁不能同時抽題；沒有鎖支援時停止寫入並明示。
- 候選紀錄使用獨立本機命名空間，與正式成績分離。不同學生隔離；不相容的資料版本或舊3／5題回合封存保留，不覆寫原答案。任務規準變更也保留原自評與筆記，要求重新檢查新規準。
- 發布開關位於 `science-rollout.js`，`SCIENCE_CURRICULUM_RELEASED` 目前設為 `true`，供主站與模組共用。啟用不再要求 localhost 或 `?scienceCandidate=1`，網址參數也不能切換開關；可明確設為 `false` 回退。這是待發布程式狀態，不能當成正式站已更新的證據。正式 profile 不因本模組練習而更新。

## 已有證據與尚待補驗

### v3 真正瀏覽器抽樣

2026-11-12 在新的本機來源、原生 Chromium 抽測真實30題單元：連續3回各10題，合計30個不同題目；第4回進入第2輪，使用10題、剩20題。重整保留相同題目與答案；第二分頁被阻擋，第一分頁關閉後可接手同一組已預留回合。這是單元抽樣，不是128單元全部端到端通過。

較早的 v3 介面抽樣包含1180px桌面、1024×600、768×1024、390×844視窗無橫向溢出，3項既有數學素材載入，以及開關自然地圖前後數學介面3個節點、各7項樣式一致。DEMO／DEMO 本機登入、登出及 Back／Forward 也有抽測。這些結果在最終資料及舊主題模式變更前取得，不取代變更後的完整回歸。

自然地圖已有 CPU 路網2,666條邊及無碰撞檢查，但測試瀏覽器停用 WebGL。實際 GPU 降落、步行、日夜光影、動物動畫、FPS與觸控仍未驗收，不能宣稱已達數學星球3D地圖的完整標準。

### 程式檢查狀態

最終舊主題真實資料檢查4／4項通過，涵蓋18個主題的原始 ID／年級／標題、每主題至少30題及題目 ID、3回各10題不重複與輪替，以及18主題以真實資料開啟數學式練習面板且不修改正式 profile。面板項目屬 DOM 檢查，不是原生瀏覽器逐題驗收。

v3 正式啟用程式與真實題庫已在獨立乾淨副本，以 Node 22.23.4／npm 10.9.3 執行鎖定依賴的 `npm ci` 及完整 `npm run check`，全部通過：資源時間18項、生活自然180項、自然地圖49項、數學星球75項、知識星圖23項、Vitest 1,196項（165檔）、型別檢查與13個建置。測試後僅更新驗收文字與移除產生的本機 QA 報告，應用程式、資料與測試輸入未變。遠端 CI 尚未執行。

## 正式驗收界線

- 真實 Firebase 認證、真實學生紀錄寫入及正式站實際頁面／資源載入時間尚未驗收；本機 DEMO 不能代替它們。
- 原生語音清單為0，最小語音測試及課程朗讀均收到 `synthesis-failed`，但 Web Audio／本機 WAV 數位播放正常。音訊錯誤不清除草稿、日期、展開狀態或焦點已有修復證據，沒有成功中文出聲或聽感證據。
- 尚未完成實體手機、Safari／Firefox、完整螢幕閱讀器、全部共享任務與分步任務的逐項瀏覽器驗收。
- 全部題目與任務仍為候選內容；課綱對照及自評不是教師正式審定、兒童試測或學生能力達成證明。觀察、合作、口述、材料與跨日等條件不能以模擬補算。
- 出版社來源依官方簡介與115學年度學校採用計畫，不是每本 ISBN 或教材逐頁認證。南一低年級官方 PDF 的直接視覺複核仍受來源連線限制。
- 正式打包排除技術驗收文件、原始 QA 與獨立預覽頁；這不代表遠端打包、CI 或部署已完成。發布開關回歸已通過，實際發布仍待核實。
