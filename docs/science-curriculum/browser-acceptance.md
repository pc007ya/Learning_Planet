# 生活與自然候選介面：瀏覽器驗收

更新：2026-11-12。環境為原生桌面 Chromium、本機隔離預覽。以下分開記錄 v3 新抽測、最終變更前的抽樣，以及 v2 歷史結果；不宣稱全面通過。

目前出版社資料版本：`science-curriculum-v3-4dcfcaae95a653f1`，110單元、3,325道可用核心題，每單元30至35題、每回固定10題。原始3,361題及其排除／延伸拆分見[題庫摘要](question-bank-summary.json)。舊主題另有18個單元、540個題位，版本 `legacy-science-candidate-v3-cf014a96b1f8fdfa`；真實資料4／4項程式檢查已通過（包含18主題面板的 DOM 檢查），不等於原生瀏覽器逐一驗收。最終全專案檢查仍待完成。

## v3 新抽測：真實題池與多分頁

2026-11-12 使用新的本機來源 `http://127.0.0.1:8878`，實際操作一個30題單元，沒有以模擬題庫替代。

- 固定10題、跨回合不重複：完成3回，每回10題，合計30個不同題目。
- 有限題池重置：第4回進入第2輪，已使用10題、剩餘20題。重複出現只能在前一輪題池取完後發生，不承諾無限回合永不重複。
- 重新載入：保留同一回合、同一題目與已保存答案，沒有重新抽題。
- 多分頁：同一學生的第二分頁被 Web Locks 阻擋；第一分頁關閉後，第二分頁可接手原先已預留的相同回合。

結果只適用於相同學生、單元及瀏覽器來源的抽測，不是跨裝置保證，也不表示128個出版社／舊主題單元皆已逐一完成上述流程。

## v3 較早介面抽樣

以下在最終資料與舊主題模式變更前完成，狀態為抽樣通過，仍需對最終版補做回歸。

- 1180px桌面、1024×600平板橫式、768×1024直式及390×844窄版視窗未見橫向溢出。這些是桌面瀏覽器視窗，不是實體行動裝置。
- 練習面板採原數學介面的白色工具列、引導角色、中央題目／四選項、提交區及分析區；3項既有數學素材成功載入。
- 先選答案再提交，提交後顯示判分與解說，由使用者按下一題；沒有倒數計時。
- 自然樣式限定於自己的介面。開啟及關閉自然地圖前後，比對數學介面3個節點的各7項樣式，結果一致。
- DEMO／DEMO 本機登入、登出、返回與 Back／Forward 抽測通過；不包含真實 Firebase 帳戶或正式學生紀錄。

## 自然3D地圖：CPU 已查，GPU 未驗

獨立自然地景包含110個地標、24條動物巡遊路線；128個可答題單元不等於128個3D地標。路網2,666條邊及無碰撞已有 CPU 檢查。

測試瀏覽器的 WebGL renderer 停用，未取得實際 GPU 降落、步行、日夜光影、動物動畫、FPS或觸控證據。直接單元清單仍是可用的備援入口；備援成功不能代表3D視覺驗收通過。

## v2 歷史抽樣，不代表目前版本

歷史版本為 `science-curriculum-v2-954846a2da1c34f7`，當時1,152題、164任務。下列結果保留為基線；當時的3／5／10題選擇已由固定10題取代。

- 24組年級／出版社／學期均可切換；一、二年級每組6單元，三至五年級每組4單元，六年級上學期4、下學期3。
- 1180×757、768×817、390×545 CSS px 抽樣無橫向溢出；窄版包含視窗調整及150%縮放，不是實體手機。
- 3題與10題回合完成，5題只檢查開題；正錯答案皆鎖定並顯示解說。當時只驗回合內不重複，不能充當新版跨回合輪替證據。
- 3題回合的完成次數與偏好在關閉、重整及重開後保留；跨版本封存未完整視覺核驗。
- 14個共享設計抽測1個「規則在幫助誰」：康軒與南一入口可見同一勾選、文字與2筆觀察；保留未經老師確認標示。
- 注音抽樣出現50組 ruby／rt、可關閉且有未知讀音留白提示；未驗全字庫發音。
- 首次載入與注音載入狀態、Tab焦點、Escape回焦、列表返回可用；後續登入與歷史導覽結果另見[登入及音訊驗收](auth-audio-acceptance.md)。
- 康軒五下「熱的作用與傳播」任務3可跳至任務2並聚焦；任務2的8張分步卡保留安全、重測、停止與原始紀錄條件，768／390px可讀。其餘18個分步任務未逐頁視覺核驗。
- 候選來源的 warn／error 查詢未見應用錯誤，但不是完整 console 或效能審計；未以破壞資源方式觸發應用錯誤頁。
