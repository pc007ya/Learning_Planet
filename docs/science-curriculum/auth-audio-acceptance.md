# 本機登入、鍵盤與朗讀驗收

更新：2026-11-12。環境：原生桌面 Chromium、本機隔離預覽。本文區分前輪歷史結果與 v3 抽樣，不把它們當成最終資料及全部模式的完整驗收。

目前出版社版本為 `science-curriculum-v3-4dcfcaae95a653f1`，3,325道可用核心題、原始3,361題、164筆保留任務，每回固定10題。舊主題版本 `legacy-science-candidate-v3-cf014a96b1f8fdfa` 另有18主題、540個題位；數量拆分見[驗收摘要](acceptance.md)。待發布程式已改由具名發布開關預設啟用，不再依賴 localhost 或網址旗標，尚須補驗新發布流程。

## v3 登入與導覽抽樣

最終資料及舊主題模式變更前，已抽測 DEMO／DEMO 本機體驗登入、自然候選入口、登出及 Back／Forward。這些不是正式 Firebase 認證，不包含真實學生紀錄寫入，也不取代最終模式變更後的回歸。

新的固定10題回合之重整續答、多分頁阻擋與關閉後接手，見[瀏覽器驗收](browser-acceptance.md)。

## 前輪 v2 登入與鍵盤結果

下列來自 `science-curriculum-v2-954846a2da1c34f7`，當時為1,152題、164任務，僅保留為歷史基線：

- DEMO／DEMO 可從主站進入自然候選模組；一至六年級可選，一、二年級各進入對應生活內容。
- 一年級目錄27個按鈕的 Tab／Shift+Tab 循環，以及題目與任務頁的首尾焦點循環通過。
- Back關閉並返回入口，Forward不重新開啟已關閉視窗；Escape、返回與重開正常。
- 登出後按Back仍顯示登入，不出現候選入口或練習視窗。
- 朗讀失敗會明確提示，文字作答、答案鎖定、解說及下一題仍可使用。

27個按鈕與舊回合長度只描述當時畫面，不是 v3 介面數量規格。

## 音訊診斷與修復證據

前輪最小原生中文、英文與預設語系朗讀，以及候選模組皆收到 `synthesis-failed`，語音清單持續為0。Web Audio 與本機 WAV 數位播放管線正常，支持問題位於當時環境的語音合成路徑，不能概括成整個裝置沒有音訊。詳見[音訊診斷](audio-diagnosis.md)。

舊版曾重現音訊錯誤重畫表單，清除未加入觀察的缺陷。修復後同一候選模組連續3次測試（含第二任務），錯誤提示出現在被點擊按鈕旁，未加入的觀察草稿、2026-11-10日期、展開區塊與焦點皆保留，整頁維持一個提示。聽題目失敗後仍可作答、看解說與前進；當時畫面的第2／5題屬歷史結果，現版固定10題。

既有回歸涵蓋錯誤分類、草稿、日期、焦點、單一提示、重試、語音清單延遲或例外、過期回呼、取消及身分切換。前輪通過不代替 v3 最終完整測試，也不表示本環境已能成功朗讀。

## 未完成範圍

- 沒有成功中文語音出聲或聽感證據；尚需於可用裝置測長任務、讀音、連續點擊與播音中切頁／背景／關閉。
- 尚未驗收真實 Firebase 登入、真實學生紀錄、全部表單焦點組合、螢幕閱讀器、實體手機及其他瀏覽器。
- 正式登入可能記錄登入時間及同步進度，仍須以核定測試帳戶或隔離環境另行驗收。
- 本輪最終題庫／模式完整回歸、遠端 CI 及發布後的實際頁面與資源載入時間尚未完成。
