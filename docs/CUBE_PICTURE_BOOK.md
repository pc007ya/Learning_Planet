# 原創方塊圖解教學書

入口：方塊工坊標題旁的書本圖示。再點一次返回原畫面；原方塊、教學進度與鏡頭不因翻書而重設。

## 教材與來源處理

參考 https://1hrbld.tw/3x3-dab/ 的觀察導向教學思路。未下載或重製該站圖片、影片、版面或口訣；沒有把它的雙公式解法重新包裝成本站原創方法。

本站書籍採獨立例子、不同章節安排及自行撰写講解，圖卡由既有整數方塊狀態直接投影。9 頁涵蓋零件、轉層、側色對齊、角塊、中間層、黃色方向、最後位置、分段動作練習。這是判讀圖解書，不是完整 DAB 課程，也不替換既有 CFOP 引導求解器。

每個示範都從其動作序列的逆序產生合法起始狀態，再逐步驗證回到完成狀態。因此圖片反映真實可達狀態，不是為了構圖任意塗色。教材明示為預先安排的例子，不能把同一串動作套到任意打亂。

## 共用產線

- `src/experiments/cube-book-data.ts`：章節、講解、標題、初始狀態、動作、相機方向與原創 SVG 繪製。
- `src/experiments/cube-book.ts`：翻頁、看圖題、單步／分鏡播放、語音、透明圖下載。
- `vite.experiments.config.ts`：建置時輸出 `modules/interactive-labs/book-v1/`，共 55 張透明 SVG 圖及兩份 JSON。教學頁使用這些同一份圖，不複製另外一套影片美術。
- `asset-manifest.json`：圖卡路徑與來源說明。
- `storyboard.json`：9 段分鏡，含完整旁白、短字幕、相機位置、cameraUp、初始 CubeState、動作、每格圖檔與停留秒數。

場景製作可讀取 initialState、camera、cameraUp，再依 moves 驅動既有 CubeView；平面影片可直接使用 frames.asset。黃色側視角有翻轉相機上向量，不能只複製相機位置。底圖與色塊、字幕始終分開。

本次提供可播放的圖卡分鏡與可重用腳本／素材，沒有宣稱已錄製新的配音影片。原有機構影片保留。

## 驗收

- 圖卡 27 個外露色格、完整安全邊界、合法初態、逐步狀態與完成目標皆有測試。
- 白十字例子特別使用「白面已齊、側色未齊」的狀態，避免只教孩子認白色。
- 後層教材另驗證前兩層已完成；不從不符合前提的任意圖硬套公式。
- 本機檢查 1024 × 600，家長說明採同格內容切換，不推高側欄。翻書操作前後原方塊皆保持白十字 3/4，返回退一步可恢復。
- 正式站部署與三種平板模擬尺寸截圖於本次對話提供；瀏覽器模擬不代表實體平板驗收。
