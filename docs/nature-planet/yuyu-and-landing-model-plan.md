# 瑜瑜模型與降落飛船：保留原設定的製作規劃

這是模型／動畫的下一步製作規劃，不是已完成模型，也不是美術核准。以 `de7a8949` 的現有角色程式、飛船 manifest 與降落控制器為基準。生態美術包已先獨立完成，不把此規劃當作阻擋地圖修正的前置條件。

## 一、不要更換角色

保留現行瑜瑜的栗棕長髮、琥珀眼、原側別的五角黃星髮夾與粉色中心、薰衣草星星睡衣、奶油色拖鞋。衣服是上衣與褲子，不改成裙子、太空裝、黑珠眼、短髮或陌生吉祥物。臉型、瀏海、髮夾位置先比對既有正式角色圖與現行正／側／背面，再修模型。

目前程式的身份描述與幾何可查證，但本次尚未目視 `images/story/little-star-v1/yuyu-paper.png` 的原圖像素，不能把程式註解當作原畫已核准的證明。原實作工作從 checkout 讀取該圖及已採用的正式角色參考即可，不要要求 Ming 重貼已存在的素材。

## 三、瑜瑜模型製作規格

- **比例先鎖住。** 保存原三視圖、原骨架根點與站立尺度，腳底為地面基準。相機距離、單元文字與碰撞半徑不要跟著任意改。
- **臉與頭髮優先。** 保留雙眼白、琥珀虹膜、眼內高光、小鼻與微笑。把超細重複毛髮改成少量連續髮束，保留長髮與瀏海輪廓，不用透明髮片塞滿畫面。
- **骨架。** root／hips／spine／chest／neck／head，雙側上臂、前臂、手、腿、膝、踝、腳掌；另加少量後髮擺動骨。必要動作不改模型的衣服／髮型。
- **先做 8 組可接入動作。** 安靜呼吸、眨眼、左右觀察、正常步行、原地轉向、短揮手、坐姿駕駛、開艙走出。行走相位依移動距離，不依牆鐘直接正弦，避免快慢速滑步。
- **預算是目標，不是已驗證結果。** 近景 LOD 12k–20k 三角形，地圖中景 6k–10k，遠景 2k–4k；6–8 材質、單角色盡量 6–10 次繪製。臉與輪廓優先，不為達數字犧牲身份。沒有做 FPS／載入重測。
- **相容接口。** 保留 `root` 與原移動控制，新增 `setState()`／`update(delta, speed)`；原程序模型作安全回退。數學與自然共用同一角色來源，不各自長出不同版本。

## 四、飛船與降落序列

### 模型

延續原白／奶油主殼、深色艙窗與暖色腳部點綴的探索火箭方向，不把自然地圖改為機械工業城。船只放在既有抵達空地。做可動的三支降落腳、明確艙門、簡潔短梯或坡板、可看見的坐姿艙位；窗材質保持低反射且能辨認瑜瑜，不加滿屏光暈。現有參考圖與原資產應先實看再定稿，不重選陌生太空船。

使用同一 `ShipRoot` 完成飛行、降落與停泊；艙門、支腳、坡板、推進器分成可控子節點。地形烘焙的舊火箭只隱藏對應節點，不刪地形／路網。載具資料載入者是唯一資源擁有者，導演不重複 dispose 共享幾何。

### 仍以 12 秒為基線的分鏡

| 時間 | 可見動作 | 重要約束 |
| --- | --- | --- |
| 0–2.6 秒 | 固定尺寸飛船從遠景進場，看到完整地形輪廓 | 用實際移動與鏡頭 dolly，不用 2.2 倍縮放冒充接近 |
| 2.6–6.8 秒 | 對準原降落點、減速、展開支腳、下降 | 地形／飛船／角色／落地點全部就緒後才下降；未就緒停在穩定等待狀態 |
| 6.8–7.6 秒 | 三腳落地，船身輕微壓縮回穩，推力收束 | 支腳接觸使用地面取樣，不穿地、不漂浮，不噴火覆蓋花草 |
| 7.6–8.5 秒 | 熄火、艙門打開、短梯／坡板到位 | 先驗證坡板末端落在安全可走地面，不伸進原道路 |
| 8.5–11.5 秒 | 瑜瑜由艙內起身、走出並抵達既有出生點 | 不瞬間出現在地面；保留原起點位置，以實際距離校準步頻；若距離過長，不硬塞三步 |
| 11.5–12 秒 | 短看向旅程方向，鏡頭交還跟隨視角 | 到安全地點後才放開行走／單元互動，整段只有一艘船與一個瑜瑜 |

相機切換要連續、別讓地形淡成白霧，也不要用白閃遮住拼接。日夜沿用當下六小時世界時鐘，夜間只靠可讀月光、艙口暖光與原路燈，不臨時切回白天。

### 可中斷與低動態

- Reduced motion：直接顯示已落地、艙門開、瑜瑜站在安全起點，不播放俯衝、鏡頭旋轉或閃白。
- 關閉／取消：停止導演、清掉未完成動作、還原可見性與控制狀態。重開不疊船、不疊角色、不多啟動 RAF。
- Back、快速重開、載入失敗、切到背景、重新取得 WebGL context 均由原生命周期處理。
- 保存世界時，停在可恢復的狀態；已抵達不要再強迫播整段降落。

## 五、交付順序與驗收

1. 原工作先接入生態美術包並完成地圖改正。這份角色／飛船規劃可並行，但不延遲已有地圖成果。
2. 以既有參考實際做瑜瑜正／側／背與飛船外觀、艙內坐姿對照；原角色未對準前，不延伸新服裝。
3. 出可載入的角色 rig、必要動畫與單一飛船實體，再接 12 秒導演。先私有元件預覽，不發布測試頁。
4. 原場景實測：臉與服裝對得上、腳踩地、頭髮不穿身、坐姿在艙內、艙門可通行、下艙不瞬移、船不縮放／不重複、六級降落點不變，日夜皆清楚。
5. 程式測試、離線幾何檢查與 Blender 元件圖都不能冒充上述實際網頁驗收。只對看過的畫面與做過的項目報通過。
