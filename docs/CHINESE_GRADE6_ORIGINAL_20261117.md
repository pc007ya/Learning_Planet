# 六年級原創能力練習整合

基於 ae8d35a，獨立入口 chinese-grade6.html；國語星球與生字練習簿都有連結。沒有將來源索引加入已完成 LESSONS，也不更改原教材或學生成績。

## 明確範圍

- 3篇原創短文，每課10題，共30題。內容涵蓋找證據、步驟因果、事實意見，不冒稱各課50題或全部六年級課程。
- 已逐題檢視短文、唯一正解、解析。修正 evidence-6 以及 viewpoint-5 錯誤的「後兩項」解析，改以內容而非位置指稱；viewpoint-6解析改引用實際選項的「比所有活動都有趣」。保留正確答案與原創來源標示。
- 六上36筆出版社索引只提供出版社、課名、學年度／學期、教育百科外鏈與未建教材／目標待核狀態。第11冊是推導，不宣稱印刷版次已核，也不提供出版社原文或朗讀。

## 操作與計時

先閱讀短文，明確按開始才計時。主站入口傳入既有一般題 timerSeconds，對應首回 round 0，預設30秒；直接進入則使用同一預設。每課一回10題，不實作升級輪次。作答期間可隨時展開短文，時間繼續。deadline使用絕對時刻，背景頁不延長時間；逾時依未作答處理。答後才顯示正解解析，下一題重新計時。退出、切來源、切課、pagehide取消回合與計時，BFCache返回維持可用。無TTS、注音、雲端儲存或發獎。

## 驗證

`npm run test:chinese-grade6`：資料結構、30題多種選項洗牌正解、36索引分離、首回計時、逾時重入、DOM閱讀與解析、退出舊callback隔離、10題結果、pagehide/BFCache。
`npm run typecheck`、`npm run build:chinese-practice`、國文既有測試與git diff --check。

這是自動化模型/DOM回歸，不是實際瀏覽器視覺、觸控、音訊或學生試用驗收；無宣稱已做這些驗收。UI使用響應式欄位、至少48px按鈕、原生details和鍵盤可用button/link。
