# 車體精修與影子挑戰 · 2026-09-08

## 實作範圍
- 保留教室、三種路面、18 項 BOM、組裝、語音與看圖題。
- 真正 3D 車體：流線車鼻、收腰曲面、輪拱側壁、深色半透明玻璃；另一款窄體競技殼、側艙與有支架的尾翼，共用底盤。
- 開放式模製底盤：電池槽／接點、馬達座、輪軸座、齒輪箱壁、補強肋、導輪座與車殼卡扣。它們是底盤細節，不冒充可獨立拆裝的新增 BOM 項。
- 所有新增模型為原創程式幾何，未下載品牌車殼或生成不能拆裝的車子圖片。圖卡仍由同一 3D 模型拍攝。

## 影子規則
- 每種跑道只保存「上一趟完成的單車試跑」，不是最佳成績。
- 30 Hz 位置／姿態採樣、以模擬秒數插值重播；最多約 120 秒、3,602 筆。只在本次實驗記憶體內保存，重新整理／離開實驗後清除。
- 影子使用當趟原始配置，呈淡紫半透明；不進入碰撞求解，也不影響實車物理。
- 中途停止、出軌、雙車碰撞與超長試跑不替換基準。另一種跑道不能借用此跑道的影子。
- 車殼與改裝卡仍可互動；錄製／重播使用同一渲染器，不新增 WebGL context。模型只在第一次啟用影子時建立。
- 追車視角在兩車接近時稍微拉遠；車頭視角保留原操作。

## 驗證
- 1024×600、1024×768、1280×720，六個模式共 18 個版面均無整頁溢出或畫面外按鈕，含展開零件表；為瀏覽器尺寸模擬，非實體 iPad。
- 單元測試覆蓋真實完賽記錄、插值、角度跨 ±π、容量上限、取消／失敗不保存、兩款車殼及底盤細節、透視狀態還原。
- 本機瀏覽器實際完成：預設平道約 16.00 秒；5:1 齒比影子挑戰約 16.40 秒，顯示「慢了 0.39 秒」（差值由未四捨五入時間計算）。
- 語音沿用既有陪玩系統；新增影子解說含首次使用、切換與結果，不宣稱已在實體平板完成音色／觸控聽測。
- 本次不含拼跑道、維修關卡與徽章任務，這些仍是後續提案。
