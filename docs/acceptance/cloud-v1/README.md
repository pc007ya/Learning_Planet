# 瑜瑜與一直打雷的小雲朵

本機預覽：cloud-storybook.html。完成後等待使用者確認，未部署。

- 20 幕、A/B/C 英文及逐幕中文、20 核心詞、每級 16 題（10 理解＋6 場景圖片題）。
- 分級為設計目標，未做 Lexile 測定。核心詞先查系列聯集，並人工核對常見詞形；沒有靠 cloud/rain/leaf/ring 等高頻舊詞充數。
- 固定房間 shared-gail-v1/bedroom.png；共用跪坐、站立、驚訝、傾聽與伸手睡衣瑜瑜。
- 箱身、箱蓋、鈴鐺各自獨立；先開蓋、鈴鐺出現並升起，第二幕接鈴聲、光圈和從鈴鐺附近散出的霧。
- 葉片有一致風向的位移與旋轉；雲朵有不同表情、輕浮動、柔和明暗與呼吸。風車只轉圖層，不轉支桿。
- 散葉與完成作品互斥，0.2 秒留白切換。結尾不把生氣當成壞事，也不保證呼吸一次就不難受。
- 鈴聲、風聲、低沉雷聲由 Web Audio 合成；保留音效開關、暫停／離開清理及減少動態設定。不以程式驗證冒稱已真人聽音評估。
- 全系列共用小星星、發光提示、單字小書、置底全景與 33×33 中按鈕、兩排等尺寸速度選擇、標題右側勾選關閉。
