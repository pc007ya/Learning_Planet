# 繪本單字（2026-10-26）

入口：英文星球 → 六年級右側「繪本單字」→「單字」。
直接網址：`/english/story-vocabulary/words/`；仍經原有登入流程。

- 匯入本機第 1–55 本的 1,189 張獨立卡，含 1,073 個不同詞彙。跨書重複詞保留各自圖片及故事出處；此數字不是核心課文涵蓋統計。
- 使用各書 manifest、詞表、索引及正式詞彙表；不把五格整頁或封面當成單張字卡。
- 圖片只轉為無損 WebP，不縮放、不重畫、不裁切；保留原尺寸及透明度。
- 預設故事順序，可選 ABC 排序、單本故事，亦可搜尋英中詞或故事名；每頁 30 張，圖片延遲載入。
- 原 500 字學習庫及新字卡共用英文聲音偏好，點一次讀一次；再次點選取消上一段。
- 原語音未選 voice，語速 0.72；現優先選裝置內可辨識的英文女聲，正常音高、語速 0.9。裝置提供何種語音由作業系統及瀏覽器決定，無法保證所有裝置都有同一女聲。
- 「英文聲音」可試聽並記住選擇；無可辨識女聲時使用可用英文聲音。沒有宣稱這是固定雲端錄音。
