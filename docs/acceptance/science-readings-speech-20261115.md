# 自然／生活注音與朗讀修正

## 問題與範圍

原題目渲染逐字建立 ruby，但使用共用的 952 字單音字表及少量數學詞組，未涵蓋自然／生活詞彙。原測試只確認有 ruby，沒有逐字檢查題幹與四選項。正式站基線實測一年級題幹 7/12、選項 36/44；六年級題幹 10/30、選項 22/61。注音開關有效，不能將問題誤報為按鈕完全失效。

## 題目與選項

採自然專用詞句注音資料，不變更數學字表。詞組優先解決多音；未知的新內容不可任意取第一個字典音。題幹、四個選項、解說及作答結果文字皆經相同渲染。注音改為與數學相同的直立側排結構，聲調分欄；關閉後回復原文，不能改題目、答案或重置計時。

資料覆蓋率與來源請見新增的 readings 資料說明及測試報告。覆蓋率表示漢字有讀音，不等同所有句子已由真人逐句審音。

## 朗讀

- 進題、下一題自動朗讀題幹；選取選項讀該選項；提交後讀答對／再想想／逾時反饋。
- 與數學共用 `learning-planet.question-speech-muted.v1`，切換同步 host state。靜音控制自動朗讀；手動「聽題目」仍可播放，與數學一致。
- `zh-TW`、rate 0.8，與數學相同的全形加減乘除等號轉讀。
- 切題、再次朗讀、離開、帳戶失效或頁面隱藏時取消先前語音；保留瀏覽器拒播與服務錯誤提示，過期 callback 不得改畫面。
- 朗讀不重置每題 30 秒期限。瀏覽器/裝置語音服務可能阻擋自動播放或發音不同，不能將 API 呼叫通過寫成實際聲音品質驗收。

## 程式驗證

- 固定語料：3361 題、標題及活動與回饋前綴，共 296,828 漢字全數有注音；另 legacy 540 題共 53,326 字全數有注音。
- 逐字 DOM 驗證六年級各一題題幹及四選項，關閉還原原文，答案與倒數期限不變。
- 多音與跨詞邊界回歸包含「每種植物」名詞量詞與「種植植物」動詞，避免最長詞匹配誤吃邊界。
- 語音事件回歸與完整 `npm run check` 通過。實際裝置與正式站另做驗收，不把合成 API 呼叫當成真人聽音驗證。
