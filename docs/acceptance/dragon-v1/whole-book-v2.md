# 整本朗讀修訂

版本：dragon-reader-v2（本機）。

- 小龍繪本移除頂欄放大場景按鈕。
- 原聲音切換改成整本朗讀：依目前 A/B/C 從第一頁開始，每頁句子與動畫完成後自動翻頁。
- 頂欄按鈕與底部朗讀按鈕均可暫停／繼續；閱讀中切換難度，保留目前頁數並按新級別重讀該頁、接續連播。
- 手動翻頁、點字／探索、進測驗、隱藏頁面會取消整本連播，避免重疊語音；最後一頁停止並提示可進入測驗。
- 單頁 Read to me 保留；其他既有故事的工具按鈕維持原行為。

檢查：TypeScript、閱讀器建置通過；小龍／語音／動作相關 14 項測試通過。瀏覽器已確認頂欄移除放大、A 級逐頁接續至第 14 頁，暫停後頁碼與句子維持不變，按繼續恢復。
