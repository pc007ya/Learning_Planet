# 不會笑的公主 · 第一版驗收

本機版本：`princess-reader-v1`，入口 `http://127.0.0.1:4188/princess-storybook.html`。

## 交付內容

- 20 頁完整故事，每頁 A／B／C 三級文字，共用環境、人物與劇情。
- 20 個核心單字：play、help、friend、together、princess、castle、gift、lonely、listen、share、smile、window、blocks、surprise、market、orange、basket、pinwheel、rain、laugh。
- 4 個正式環境：城堡庭院、城堡遊戲室、市集／廣場、雨棚。背景與角色、積木、風車、橘子、籃子、紙帽、椅子分層。
- 20 個探索任務，包括積木、橘子入籃、分享風車的拖曳／點選替代操作及順序點選。
- 逐字點讀、單頁朗讀、依難度整本朗讀、自動翻頁、句子同步人物動作、方向鏡射、自己讀、慢速設定。
- 每級 16 題四選一：10 題單字／故事理解＋六格構圖衍生的 6 題劇情配對。
- 題目、選項可聽英文；先選取、可改選，提交後才判分。提交後仍可點讀而不改分。
- 書架第二排加入新書；鼠尾草綠／奶油色書脊，短書名 Princess & a Smile，風車圖徽。書脊轉封面後翻開。

- TypeScript 型別檢查通過；閱讀器與書架建置通過。
- 7 個相關測試檔共 37 項通過，含舊四本書回歸檢查。
- 瀏覽器尺寸 1024×600、1024×768、1280×720；每個尺寸檢查 A／B／C 各 20 頁，共 180 組，無文章或整頁溢出、無失效的場景 img。初次小尺寸檢查時坐姿素材尚未完成，補入後已重跑全部 60 組小尺寸頁面；checks.json 保存最終結果。
- 20 個任務逐頁實際操作完成。拖曳任務驗證了其點選物件→點選目標的替代流程；原生手指拖曳未以實體平板另測。
- A 級 16 題實答，刻意答錯一題，結果 15/16；B、C 級實答結果各 16/16。各題卡與提交控制在對應橫放尺寸未溢出。
- 第一題先選錯選項時沒有判分；提交前改選正確選項正常。提交後再點錯選項仍維持原本答案與分數。
- A 級整本朗讀從第 1 頁到第 20 頁，途中第 17 頁暫停／繼續正常；最後停止並提示書末測驗。另測朗讀中切 B 級，當頁改讀 B 級文字；進入測驗後朗讀停止。
