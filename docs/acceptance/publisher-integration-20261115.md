# 生活／自然課程整併

- 僅整併同年級、同學期且明確同主題的來源單元。110 個來源單元形成 88 個入口；22 對合併。同名但不同主題不強併（家人感謝／校園幫助者）。完整決策表：`data/science-curriculum/integration-map.json`。
- 全部來源活動、題目、實作、來源引文保留；沒有因題幹相近刪除內容。完全一致題目保留來源資料，僅可在新抽題政策排除重複。現有 22 組無完全一致題目。
- 學生介面只選年級、學期，不再選出版社。來源仍可在教材來源展開查看。
- 每年級學期生成一組 `all-gN-tN` catalog/exercises，地圖只下載目錄、進入練習才下載當期題庫；不下載其他年級。生成由 npm check 前置流程執行，不提交重複題庫。
- 合併入口沿用既有實體站點 ID，舊來源單元深連結解析到新入口。地形與導航未重建，來源建築幾何仍存在但重複入口不顯示。
- 舊紀錄不刪除；合併來源紀錄複製到整合單元，保留答題快照、觀察記錄。若已有另一個進行中回合，來源未完成回合存作 interrupted，避免覆寫。每個來源只整合一次。
- 原主題 legacy 練習不改；仍是每回 10 題，題池依整併後題目數輪替。

## 驗證
新增測試核對 110 來源 ID、全部活動 ID、全部問題 ID 一對一保留；12 組資料結構有效、每組僅對應年級學期；舊來源連結、無破壞紀錄整合、12 格 UI 篩選與練習往返。
