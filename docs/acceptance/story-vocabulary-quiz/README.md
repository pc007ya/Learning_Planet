# 繪本單字測驗（2026-10-26）

入口：英文 → 繪本單字 → 單字，可切換「聽聲音選字卡」與「看圖聽音選單字」。

- 第 1 種：播放英文，選四張完整單字卡之一。
- 第 2 種：顯示題目圖片，CSS 不透明遮罩遮住下方 40% 文字區，播放英文，選四個英文文字之一；作答後揭開遮罩。
- 可複選故事、全選或清除，10／20／全部題數；題目與干擾選項均來自指定故事。
- 大小寫與空白正規化去重；不改原始學習字卡。同一回合單字不重複，四選項也不重複。
- 每題只能計分一次，立即回饋正確字義，手動下一題；結束顯示成績、錯題與錯題重練。
- 開始／下一題由點擊觸發語音，可重播，沿用共用英文聲音；離開取消播放。
- 無選書或少於四個不同單字時禁止開始；圖片與語音失敗顯示提示。

驗收：完整 npm run check 通過。新增測試檢查全部書、單書、多書範圍、選項唯一、數量上限、空範圍、錯題範圍。Chrome 實際操作兩種模式、10 題成績、錯題重練、回到瀏覽與語音呼叫均正常，無頁面錯誤。390×844 手機尺寸無橫向溢出，遮罩正常（mobile.png）。未用實體 iPad／iPhone 驗證。
