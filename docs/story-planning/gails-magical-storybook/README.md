## 確認的規格

- 全系列 20 冊，每冊 20 個場景。中文主角瑜瑜，英文 Gail。
- 同一故事與畫面對應 A / B / C 三級文本，每次只呈現所選級別。
- A Read Along：1–2 句／頁，重複句與簡單敘述；寫作目標 BR–300L。
- B Early Reader：2–4 句／頁，簡單過去式、because / but；寫作目標 300L–500L。
- C Independent Reader：3–6 句／頁，完整敘事、因果與情緒詞；寫作目標 500L–700L。
- 上述為原對話的寫作目標，並非官方 Lexile 評測結果。系列主版本目標 350L–550L，第一冊草稿另收窄為 350L–500L。
- 每冊 10 個核心詞：6 個動詞／形容詞 + 4 個奇幻名詞，按級別調整難詞。
- 每冊 2–3 個句型；第 20 場景以節奏、重複或押韻收尾。
- 書末 10 題：聽音選圖 2、看圖選字 2、填空 2、排序 1、因果 1、情緒 1、主旨 1。
- 跨冊安排已學詞彙重現；每個場景保留詞彙、句型、情緒、閱讀能力與互動候選資料。
