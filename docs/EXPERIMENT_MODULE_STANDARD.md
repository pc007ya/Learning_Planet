# 實驗模組共用製作規範

使用者確認日期：2026-09-07。適用於後續新增與改版的所有實驗模組。
對象為 7–9 歲孩子與家長。以浮力的寶物拖曳、回力車的圖示導覽與看圖題作為體驗參考，不複製題材不相符的圖片。

## 1. 圖片優先，文字精簡

- 「回首頁／返回」使用框內左箭頭；「考題」使用鉛筆圖片，在最上方切換，不另占一行或放到頁面底部。
- 語音、重聽、筆記、重玩、提示等優先用簡單、清楚且一致的圖示。圖示可保留必要的極短標籤，避免長句按鈕與整段操作文字。
- 每個圖示按鈕提供正確的可讀名稱（例如 aria-label）、鍵盤焦點與選取／開關狀態；不能只靠顏色辨識。主要觸控區至少 44 × 44 CSS px。
- 題目使用圖片情境、操作示範或圖形比較引導；答案以獨立圖卡選取。完整題意与解說交由語音與可存取文字承載，不把大量文字烘焙在圖片裡。
- 不以 Emoji 冒充應有的教材物件圖；簡單介面符號可沿用一致的圖示系統。

## 2. 不用下拉選單，不做下滑長頁

- 孩子的實驗操作介面不使用 select、下拉式選單或以自製彈出選單替代。改用可直接看見的物件卡、拖曳、圖卡選擇、開關或分段按鈕。
- 旋轉與拆卸採開關搭配直接操作；力量與環境參數優先用具象圖示與少量檔位，不堆疊長文字及滑桿。
- 以平板橫放為優先，至少檢查 1024 × 768、1024 × 600 與 1280 × 720。主實驗、側欄、考題及零件清單均不應靠上下滑動完成。
- 內容過多時採框內標籤切換、分步或明確分頁；不要把長頁藏進可捲動側欄，也不要用 overflow:hidden 裁掉控制項假裝合格。
- 直向與較小畫面同樣優先採分頁／分步；無障礙文字放大時不得裁切或禁用使用者縮放。若放大造成必要捲動，須單獨說明，不把它當成一般平板版面的預設。
- 切到考題、筆記再返回，保留物件位置、操作參數與探索進度。

## 3. 視覺與圖片品質

- 星際深色半透明面板配白色文字，保持清楚對比；不能出現白字白底或深色字融入面板。圓潤、親切、有明確按壓回饋，不做成人控制台式密集介面。
- 背景可採生成的玩具場景或實驗場景；主體清楚、材質與比例一致，不用複雜裝飾搶走操作焦點。
- 先定義物件、視角、留白與互動需求，再生成；逐張檢查外形、教學正確性、透明通道、完整邊界及小尺寸辨識度。
- 生成結果不合格或生不出來，先搜尋可靠的網路照片作參考，或尋找授權清楚、可合法使用的素材；不得將搜尋到的圖片一律視為可直接上架。記錄來源、授權與用途。
- 不接受殘片、錯誤物件、假透明棋盤格、被裁掉的把手／底座／輪胎、不相關裝飾、跨模組混用或題目與圖片不符。未解決的素材標為待補，不宣稱完成。
- 保存原始素材及生成提示，新版使用版本化路徑，不覆蓋原始檔。

## 4. 底圖、物件與互動分層

- 底圖只負責環境；需要移動、旋轉、拆卸、比較或變化的物件，必須是獨立透明圖片或真正的 3D 元件，不可烘焙進底圖。
- 一個可重用物件優先一個檔案；實驗資產不強制先做拼圖大表再裁切。若使用圖集，仍須逐件驗證，不容許鄰格殘片。
- 文字、按鈕、標籤、命中區、動畫與物理狀態分離。裝飾層不攔截觸控；縮放後圖像與命中區仍對齊。
- 同一環境的不同條件（例如平路／石頭路）保持構圖、尺度與接觸位置一致，只改相關條件；不能換背景後物件漂浮或陷入地面。
- 保留拖曳、旋轉、連接、拆卸、觀察、重玩等真實互動，不把功能改成只能觀看的漂亮圖片。

## 5. 共用能力與語音

- 優先沿用現有共用工作區、模式開關、指標操作、語音、考題、觀察紀錄與資產載入；新模組提供題材資料和專屬規則，不各自複製整套頁面與事件。
- 語音涵蓋入門、操作、物件／零件、觀察、題目及回饋；保留圖示重聽與關閉功能。遵守瀏覽器需使用者手勢啟動的限制，不讓講解重複排隊。
- 對鍵盤與無語音裝置保留可存取替代方式；簡化的是畫面，不是教學內容與操作能力。
- 保留既有實驗；新增同名實驗只在新項目加「（新）」。不以建立新引擎為理由刪除原功能。
- 避免不必要的持續渲染，背景／離開時停止動畫、語音並釋放資源。低記憶體裝置上逐項驗收，避免同時開多個 3D 場景與批次生成。

## 6. 交付驗收

- 檢查素材完整、圖片題意正確、底圖與物件分離、圖示可讀、白字對比與觸控命中。
- 實際操作模式切換、拖曳／旋轉、環境條件切換、考題往返、語音重聽、重玩与離開。
- 在目標橫放尺寸檢查頁面與各面板溢出；不得僅依程式碼推測無捲動。
- 提交場景與看圖題截圖，注明實測尺寸、部署版本及未完成項。使用 GitHub 發布時，確認部署成功並驗收正式站，不以本機截圖冒充正式站。
- 不宣稱瀏覽器模擬尺寸等於實體 iPad 驗收；圖片美化也不等於工程或科學模型已精確驗證。
