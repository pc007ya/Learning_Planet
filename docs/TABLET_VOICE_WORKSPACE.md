# 平板橫放與語音陪玩（2026-09-07）

適用：浮力實驗室、簡單機構：時鐘、簡單機構：回力車。既有其他實驗不受此版面改動影響。

## 版面

- 900px 以上、600px 以上高度的橫向畫面，以視窗高度配置模型、零件與操作面板。
- 筆記、挑戰、操作方法與家長補充保留於原生對話框；關閉後回到原來的模型狀態。鍵盤 Escape 可關閉。
- 小螢幕、直向或放大文字時允許正常捲動，避免為了單畫面而裁掉內容。側欄保留溢出捲動作為備援。
- 主要操作與零件清單按鈕至少 44px 高；模型中的小編號另有清單按鈕替代。
- 白字、星際半透明面板、圓潤漸層按鈕；支援減少動態效果偏好。

## 語音

- 使用裝置的 SpeechSynthesis，優先 zh-TW，其次中文聲音，速度 0.88。未另外上傳文字或錄音。
- 首次需點「開始語音陪玩」以符合行動瀏覽器的播放限制。也能直接點「再講一次」。
- 說明包含入門、觀看模式、零件用途、物品選擇、操作結果、觀察紀錄、問題及作答回饋。
- 新講解取代舊講解，不累積排隊；關閉語音、離開實驗、切到背景或關閉說明卡時停止播放。
- 不支援語音或播放失敗時顯示提示，文字講解仍完整保留。聲線與音質取決於裝置已安裝的中文語音；尚未進行實體 iPad Safari 聽感驗收。

## 驗收

- 1024 × 768 回力車：頁面 1024 × 768，側欄 clientHeight / scrollHeight 均 640，主畫面不需上下捲動。
- 1024 × 600 浮力：頁面 1024 × 600，側欄 clientHeight / scrollHeight 均 472。
- 時鐘前進一圈、挑戰正確回饋；回力車出發、筆記紀錄；浮力紙船預測／入水均經介面操作。
- 語音測試涵蓋預設不自播、手動重聽、中文聲音與速度、新講解中斷舊講解、舊回呼失效、錯誤提示。
- 自動化測試通過不等同實機聲音品質驗收。
