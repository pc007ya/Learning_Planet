## 使用

本機 `index.html` → DEMO 體驗登入（帳密 DEMO）→ 週考 → 模擬考。正式版本使用現有學生帳號身分。考後依最低三類推薦補練；測驗成績不寫入原 `weeklyExam` 或週考雲端紀錄，也不重複發 XP／星星幣。

發布時應包含：index.html、gifted-learning-path.html、modules/gifted-exam/*、modules/math-foundations/zhuyin.mjs、modules/math-teaching/curriculum-roadmap.json。`work/` 為分析暫存、原始題本與 QA，不是網站依賴；請勿打包。
