## 詞表來源與版本邊界

官方入口為[教育部教育百科生字詞彙表](https://pedia.cloud.edu.tw/Bookmark/TextWord)。依頁面實際列出的 115 上、年級、出版社索引取得課程 ID，再讀取其 `TCollection` 課頁；沒有利用 ID 命名規律猜課次。

`coverage-sources-grades45.json` 保存六個索引的精確 URL、來源 SHA-256，以及 72 課的來源 URL、原始標題、分類數與依原順序計算的詞表 SHA-256。72 課的索引題名與課頁 heading 完全一致。每課詞表 hash 定義為 UTF-8 `JSON.stringify(vocabulary.map(({category,text})=>({category,text})))` 的 SHA-256，排除後加注音與編輯說明。

新版課資料保留 `sourceTitle`、`title`、`indexUrl`、`sourceUrl`、`checkedAt`。課綱與印刷版次未提供，保留 `null`；第 7／9 冊由年級與學期推導，保留 `volumeDerived: true`。`status: 已核` 只表示來源詞表已核，不表示所有注音或出版社課文逐頁標音已核。

## 注音規則與待核分界

新批使用獨立的 `sounds-audit-grades45.json`、`sounds-single-grades45.json`、`phonetics-status-grades45.json`。查音來源為教育百科呈現的教育部《國語小字典》、《國語辭典簡編本》、《重編國語辭典修訂本》。保留 provider、各組候選、原始來源 URL、實際查核日期及聲調核查狀態。線上版本未知，不套用下載版號。

- 整詞採小字典、簡編本、重編本的明示優先順序；同一提供者有多組音時保留全部，不取第一組當唯一答案。
- 單字須檢查三部字典的候選音聯集。確實只有一音才直接採用；多音單字只有在本課唯一已核語詞提供一致選音時，才可作有說明的編輯選音，不宣稱為出版社印刷注音。
- 沒有整詞音時，只組合真正無歧義的官方單字音，明示不是出版社標音；不能從其他語詞借語境來替缺少的整詞定音。
- 多音整詞只保留每一組都一致的音節；歧異音節留空。多音單字沒有足夠語境也留空，不採常見讀音預設或跨課覆寫。
- 解析教育百科標音 DOM 的 `tone-0/1/2/3/4` 聲調，輕聲標記放前方，避免只取文字而遺失聲調；保留個別讀音組，不把多組讀音串成假長詞。
- 重用舊資料僅限已核、長度／聲調格式有效的字典事實，保留原查核日；不重用舊課的語義預設、教師覆寫或特例。
- 新批原有 2,179 個不同整詞／字元查音 key，內含 1 個人名分隔符「‧」。有效查音範圍排除該單符號後為 2,178 key。`海倫‧凱勒` 原詞與位置對齊的注音陣列仍完整保留；分隔符無注音、不作國字練習，也不單獨算待核。

最終可用音、編輯選音、缺整詞與待核的實際數量，以本批 `phonetics-status-grades45.json` 的 `methods`、`lookupGaps`、`lookupErrors` 與逐課 `pendingEntries` 為準。單字解歧數與詞條數的單位不同，不把所有方法計數直接相加。

本次最終 2,178／2,178 查音 key 均有查核記錄，包含 1,536 筆本日新查與 642 筆重用已核字典事實；`lookupsComplete: true`、`interim: false`、抓取／解析錯誤 0。另新增 597 個舊單字表沒有的真正單音字。

以**詞條**為單位，2,059 條分為：

- 922 條無歧義官方單字音。
- 843 條唯一官方整詞音。
- 206 條有註記的同課語詞編輯選音，不是出版社印刷注音核定。
- 1 條以已核單音字組成的詞音，不冒稱有官方整詞音。
- **87 條待核**：67 單字、14 多音詞、6 缺整詞而仍含多音／缺音的組合。以上合計 1,972 條沒有待核國字音槽，但不能因此宣稱全部已核出版社標音。

- 舊 `lessons-115-upper.json` 與新 `lessons-115-upper-grades45.json` 合併讀取，舊資料不重寫。

- 原詞目與來源標籤保留分隔符；`practiceRows` 只產生 Han 國字練習列，注音待核判斷使用相同規則。

- 自訂字的既有音表與既有優先序不變；新增單音表只增加舊表沒有且確實無歧義的字。
- 不修改登入、教師角色／班級隔離、其他國文題庫或實驗模組。未新增筆順 ID、動畫、發音檔或外部服務依賴。

## 重現與測試

Python 環境需 `lxml`（本次使用已安裝的 6.1.1），來源匯入器本身只用標準函式庫。Node 沿用專案既有安裝，不修改 lockfile。

```
python3 scripts/import-chinese-grades45.py
python3 tools/compile_chinese_grades45.py --fetch
python3 -m unittest discover -s tools -p 'test_*chinese_grades45*.py' -v
npm run test:chinese-practice
npm run check
npm run build:chinese-practice
node scripts/check-chinese-practice-title.cjs
node scripts/check-chinese-grades45.cjs
```

有完整來源快取時，匯入器 `--offline` 可驗證確切來源 snapshot；查音編譯器不加 `--fetch` 可離線重編，絕不使用舊的全量 `compile_chinese_catalog.py` 覆蓋原課資料。新匯入器 fail-closed 驗證年度、年級、出版社、canonical、課名、類別、重複 ID／詞條、實際詞數與官方路由。

舊 93 課的每個欄位以原始資料的 canonical JSON SHA-256 回歸保護：`82d99de680dcebb59be3019d60c2dca9d2b0835037fa848aaf3d315fcc5a8669`。新資料測試另核六冊數量、72 課來源詞序 hash、題名差異、聲調格式、待核索引、跨來源去重與保守合音、非國字分隔符、115 下與六年級不代填。

Mocked-DOM 回歸涵蓋原始程式及實際建置 bundle，但**不是實際瀏覽器、iPad 或 PDF 視覺驗收**。本批沒有重新啟動先前被拒絕的瀏覽器操作，也不換路繞過。高年級分頁與來源附錄只驗證產出的 HTML 結構，不將其描述為已實測紙張裁切或實機觸控。
