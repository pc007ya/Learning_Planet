# 立體幾何教學桌預覽

入口：https://pc007ya.github.io/Learning_Planet/math-geometry.html

參考概念：https://www.aistempilot.com/tools/geometry-calculator/
自行製作 Three.js 幾何、互動與版面，未複製對方素材。

- 周長：著色外框；面積：單位方格。
- 體積：單位積木、逐層播放、層數控制、分層間距。
- 表面積：六面拆解、相對面同色、可點選面或面按鈕。
- 長寬高 1～20 整數、cm/mm/m。單位切換改題目尺度，不換算數值。
- 可旋轉、縮放、三面／俯視。保留提示與回顧。
- 尺寸列右側的喇叭開啟後，概念、單位、套用、視角、逐層播放、六面選擇、提示與回顧會朗讀對應的繁體中文說明；關閉或離開頁面時停止朗讀。使用瀏覽器語音，無語音環境有文字提示。
- WebGL 失敗時只保留數值解說，不宣稱立體可用。
- 已在一年級數學列表最下方新增「面積探索」「體積探索」卡片，分別直接開啟對應教學模式；原三至五年級正式題目單元保留不變。已部署至 GitHub Pages。

驗證：1～20 全組合模型測試、無效值測試；既有分數測試，共 8 項通過。教學 bundle 建置、TypeScript 通過。
瀏覽器：4×3×2 周長14、面積12、體積24、表面積52；1層12顆；前面8平方公分；20×20×20為8000顆，無 console error。
