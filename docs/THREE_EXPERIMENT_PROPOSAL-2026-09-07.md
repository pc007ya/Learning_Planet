## 共用架構

```text
經審核的 Experiment Spec + 素材清單
                  ↓
Experiment Engine：階段、動作、模型、紀錄、評量
          ↙                         ↘
Three.js 場景                    HTML 教學面板
物件／拖曳／旋轉／量測            預測／提示／觀察表／作答／總結
```

Three.js 負責呈現與物件選取，不負責自動推導磁學、電路或課程。每個科學領域仍需經測試的模型外掛；相同模型的不同關卡才主要用 JSON 擴充。不要允許 JSON 執行任意 JavaScript。

建議新增 src/experiments/core、renderers、models、widgets、specs、assessment；沿用現有地球模組的掛載與卸載經驗。新模組使用獨立入口與延遲載入，避免把所有 3D 資源塞進首頁。

Spec 必備：schemaVersion、實驗 ID、內容版本、適用年級、學習目標、課綱待核對來源、素材 ID、物件初始位置、互動種類、參數範圍與單位、白名單模型及其版本、五階段轉移條件、觀察證據、題目與評分、分層提示、模型限制、審核與發布狀態。

操作記錄保存時間、物件、動作、參數與內容版本；模型以固定步進與明確初始狀態支援重播。學習進度先適配既有儲存方式，不直接改寫舊實驗的進度鍵。

## 第一個交付：磁鐵原理實驗室（新）

1. 預測：選擇吸引、排斥或不確定，不因猜錯扣掉探索資格。
2. 操作：兩塊磁鐵在固定桌面拖曳、旋轉，可按鈕微調；自由視角不與拖曳搶手勢。
3. 觀察：以磁極實際位置及方向計算簡化作用，加入阻尼與距離限制，顯示距離與方向。數值若未校準，不標成真實牛頓量測。
4. 作答：完成同極、異極與不同距離的試驗紀錄，再回答原因。
5. 總結：顯示原先預測、實際結果、修正後解釋；示範播放可暫停、重播，教師提示先用審核過的腳本。

先驗證受限方向的磁極模型，再開放任意角度；不可把目前左右判斷加上旋轉外觀就稱為完整磁場模擬。

## 視覺與效能規則

- 外框、工具列、觀察表、題目、提示統一星際深色半透明與高對比文字；保留既有角色和插畫。
- 實驗物件可沿用剪紙／色鉛筆貼圖，採 2.5D 桌面；不必全部換寫實 3D。文字、按鈕放 HTML 層，避免縮放後模糊。
- 物件與背景分開；圖片透明安全邊界、攝影機取景邊界、拖曳範圍分別驗證，不能只靠 overflow:hidden 藏問題。
- 每次只啟用目前實驗的渲染器；背景暫停、限制解析度、依需要重繪；離開時清理紋理、材質、幾何與事件。
- 支援觸控、鍵盤及不必精準拖曳的替代操作；WebGL 失敗要有可理解的降級介面，不呈現空白。

Three.js 官方依據：[物件選取](https://threejs.org/manual/en/picking.html)、[資源清理](https://threejs.org/manual/en/cleanup.html)、[依需要重繪](https://threejs.org/manual/en/rendering-on-demand.html)。

## AI 教材新增流程

管理員輸入主題 → 生成五份草稿 → 結構與素材檢查 → 科學及教學審核 → 桌機／平板互動驗收 → 人工核准發布 → 可回復舊版本。

五份草稿沿用 lesson_outline.json、experiment_spec.json、questions.json、teacher_script.json、asset_manifest.json。模型金鑰只留後端。新增未知模型或素材時退回草稿，不捏造可執行的互動。AI 審查輔助人工，不直接自動上架。

例如「五年級自然：水溶液酸鹼性」，先核對年級目標，再確認酸鹼與指示劑模型已實作；Three.js 只呈現器材和顏色，不可用任意混色冒充酸鹼反應。沒有合格模型就只生成待審課程，不發布實驗。

## 推進與驗收門檻

第一階段：修正已知科學概念、建立 Spec 驗證器、共用面板與磁鐵新版。第二階段：以光影和電路驗證引擎能跨模型重用，地球公轉另接共用教學流程。第三階段：植物、水三態、侵蝕；最後再做大量 AI 草稿生成後台。

每階段需交付：模型單元測試、五階段完整操作測試、重播一致性、缺素材與 WebGL 失敗處理、桌機及 iPad 尺寸截圖、切換實驗資源清理檢查、舊六個入口回歸測試。截圖至少包含入口、操作中、觀察表、總結及窄畫面；靜態截圖不能代替互動通過證據。

本次未進行逐張素材、逐題或所有裝置的重新驗收，既有截圖中的裁切與色卡問題不因此視為已解決。分享的 ChatGPT 連結未取得對話正文，方案以使用者貼出的內容與本地原始碼為準。
