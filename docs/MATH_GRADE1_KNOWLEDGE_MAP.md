# 小一數學知識星圖

入口：數學星球 → 一年級 → 第一張「小一知識星圖」。獨立頁面為 `math-knowledge-grade1.html`。

## 課綱與內容

- 依教育部數學領域課綱印刷頁 19–20 的小一學習內容建立 22 個核心概念，7 條航線。
- 官方來源：https://edu.law.moe.gov.tw/LawContent.aspx?id=GL001788
- 內容代碼：N-1-1 至 N-1-6、S-1-1、S-1-2、R-1-1、R-1-2、D-1-1。
- `grade1.mjs` 的說明為自行整理摘要；概念連線是本站的教學建議，並非課綱規定的先後順序。
- 27 個既有課號與 ID 保持原狀，`courses.json` 與主頁一一對應。
- 直式 50／99 以內加減保留為自選延伸（正式直式教學對應 N-2-2）；連續加減挑戰亦不作為核心通關門檻。
- 原月曆課程含延伸活動；核心節點僅對應簡單日期與日常時間用語。
- 本版自行建立台灣小一概念、資料與程式，未移植 cn-math-taxonomy 的題庫、資料或程式。

## 互動與紀錄

星點可開啟對應的既有練習、教學影片與互動教學；教學按鈕只在原單元已有教學時顯示。教學與影片不存在時不產生空連結。獨立頁面的課程連結會回主站登入後開啟該小一課程。

星圖以 dialog + iframe 開啟，主頁登入與目前學員狀態維持掛載。父頁只傳遞單元資料與練習紀錄布林值，不傳姓名、密碼、token 或完整個人資料。雙方檢查訊息 origin、source；父頁再驗證單元白名單，動作前確認仍為同一學員。

紀錄讀自目前學員的 `cleared`、`dailyMastery`、`masteryHistory` 與 `mathQuestionHistory`。只標示「已有練習紀錄」，不把整課完成推論為個別概念已掌握，不改動原進度或獎勵。此版不包含自適應診斷評量。

## Three.js

本模組直接相對引用官方 `three@0.187.0` 的本地副本，執行時核對 `REVISION === '187'`。原站既有依賴保持原狀。第三方授權與來源見 `modules/math-knowledge/vendor/three-r187/`。

主要顯示使用 WebGLRenderer、三維節點、曲線與粒子星雲；無 WebGL 時採 r187 相機的 CPU 投影相容星圖，再失敗則使用可操作概念清單。支援轉動、縮放、重設、航線篩選、延伸切換、鍵盤操作與減少動態效果。

## 驗證

`npm run test:math-knowledge` 檢查課號完整性、課綱對照、圖形無循環、學員紀錄語意、r187 版本、入口順序、訊息隔離、登入後課程連結。已加入原站 `npm run check`。

瀏覽器驗收環境停用 WebGL，因此可實際檢查 r187 CPU 星圖與操作；GPU 版實際渲染仍需在支援 WebGL 的裝置確認。

## 圖像優先介面（2026-11-01）

星點、航線與前後概念沿用數學星球既有彩色插圖，保留短名稱；動作以影片、積木、鉛筆圖形按鈕呈現。課綱代碼、長目標、延伸說明與紀錄語意收於「給大人」，供需要時查看。湊十框、位值與運算符號採精確 SVG，避免數量示意錯誤。行動版依比例拉開縱向節點，維持看圖選擇。

## 練習進度光效

有練習紀錄的節點保留彩色，顯示柔和光環、緩慢繞行星光與勾記；未有紀錄的節點降低彩度與亮度，點選或鍵盤聚焦時暫時提亮。兩端都有紀錄的星軌會淡淡點亮。圖卡與前後概念縮圖沿用同一狀態。所有節點仍可點選，不新增門檻或修改學習紀錄。

光效可用原「暫停星空」一起暫停，並尊重裝置的減少動態效果設定。獲得光環只依目前學員從小一入口提供的紀錄；獨立頁未連結學員時，不產生已獲得光環。WebGL 和 CPU 相容星圖共用 HTML 光環，保持同樣的狀態表達。
