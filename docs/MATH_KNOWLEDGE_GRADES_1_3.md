## 介面

返回箭頭與「數學星球・年級」同列，刪除獨立頂欄、品牌星號和暫停按鈕。保留裝置的 reduced-motion 偏好。已玩彩色柔光、未玩淡灰、選取暫時提亮；不把選取或看圖操作寫成完成紀錄。

三年級的 26 星點依實際座標與畫面安全邊界取景，WebGL 與 CPU 相容 renderer 共用 `layout.mjs`。手機長名稱可換行；星圖仍支援縮放、航線篩選和圖卡清單。

## 二、三年級課綱界線

- 二年級 N-2-9 的核心是分裝、平分操作，不列除式；正式除法 u18/u9 放自選延伸。
- N-2-10 核心限連續量的幾分之一；原有分數課 u17/u10/u11 包含更廣的內容，置於延伸。
- 原測量實驗 u30 含角度與標準重量單位，與空間推理 u31/u32、腳數推理 u12 等歸入自選延伸。
- 二年級三位數減法核心限一次退位，超出部分於成人說明標示；未改寫原題庫。
- 三年級角度核心以操作比較與直角為主，u51 的銳角、鈍角名稱作延伸認識；未將量角器或正式度數計算標成三年級核心。

## 補充看圖操作

`labs.mjs` 補足原站沒有獨立課程的概念：大鈔、簡單估算、分裝平分、單位分數、形體特徵、周界、重新分類、加減檢查、乘法旋轉行列、三數相加，以及三年級整數數線、四則估算、兩步驟、正長方形、展開圖。數量和幾何以精確 SVG 生成，圖示採透明底、本站柔和配色。

這些是星點內的短操作示範，狀態只在當次星圖保留；不是新增完整題庫或評量單元，不產生獎勵、不寫個資或雲端紀錄。沒有既有單元的星點顯示「看圖探索」，不虛構影片或練習連結。S-3-4 的展開圖是圖示開合體驗，不以此取代實際摺紙操作。

## 主站與紀錄

父頁維持原登入與目前學員掛載，只傳當年級單元資料與 `practiced` 布林值。Iframe 使用同來源、精確 source 驗證；launcher 再以年級課號與單元白名單驗證。返回恢復原入口焦點；播放、教學、練習動作前再驗證學員及年級沒有改變。每年級獨立頁的課程連結會在主站登入後恢復該年級及該單元。

## 驗收

`npm run test:math-knowledge`：20 項檢查，包括三年級完整課號、各學習內容碼涵蓋、DAG、圖像、數量、相機在桌面／848 平板／390 手機的取景、跨學員與跨年級隔離，以及登入後課程恢復。另跑原站 TypeScript 與 Vitest 檢查。

瀏覽器以固定假資料驗證三年級課程 callback、返回、光環與灰階、平板及手機完整星點、大鈔加減及展開圖開合。瀏覽器環境停用 WebGL，因此畫面驗收涵蓋 Three.js r187 CPU 相容版；GPU 版共用資料、相機與 HTML 圖示，仍需支援 WebGL 裝置確認。
