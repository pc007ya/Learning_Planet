# 3D 地圖輸入與步行修正（候選驗收）

## 原問題與修正範圍
- 數學 1–3、自然：canvas 被共用 pointer-events:none 規則禁用；分離可操作 canvas 與透明標籤覆層。
- 同兩種地圖：新增 .6–2 倍連續縮放、滾輪、雙指與明確按鈕；飛行/降落保留導演鏡位，雙指結束不觸發點地。
- 數學 1–3：導航高度對準真 GLB 地表，保留障礙、島邊及斜坡檢測；不是放寬碰撞來繞過故障。
- 數學 4–6：原版僅有可旋轉浮島，新增原瑜瑜角色、可見實體橋、島內安全區、晶石碰撞及安全尋路。
- 方向鍵、WASD、觸控方向按鈕與安全地面點擊；失焦、背景及關閉停止移動。
- 數學 1–3 與自然步速由 2.4 提高為 4.2 世界單位/秒；腳步依實際位移驅動，不讓動畫加速冒充角色加速。

- 數學 4–6 的較小島圖以 2.4 單位/秒移動（原候選 1.6，增加 50%）；八島相鄰路程模擬約 2.17–2.97 秒。

## 可重現自動測試
`npm run test:math-planet-v11` 包含真 GLB 導航、碰撞、輸入覆層、縮放與加速測試。
`npm run test:nature-planet` 包含自然 runtime 與縮放手勢。
`npm run check` 包含全案測試、型別及建置。

- 三張數學地圖共 1791 條導航邊安全、78 個站點可達。
- 20/30/60/120 FPS 鍵盤與路徑移動兩秒均 8.4 單位，超大單步也不穿障礙，島邊保留。
- 4–6 年級 1–8 島布局的路徑連續性、晶石及虛空邊界測試。

## 驗收界線
CPU 合成事件不是實體雙指驗收。Mac 瀏覽器另測桌面點擊、滾輪、按鍵與平板尺寸，且必須測普通動態降落，不只 reduced-motion。
未收到 Mac 候選驗收及正式站版本證據前，本文件不代表已部署或視覺驗收完成。
