# 四驅車車殼重製

## 造型與範圍
參考 Tamiya Cyclone Magnum 的低車身／導輪配置、小米 SU7 的連續曲面、Ferrari 296 GTB 的緊湊座艙與車肩比例；只研究造型，不使用商標、原車貼圖或品牌模型。製作原創流線小跑車，保留既有底盤、18 項零件、裝配、透視、語音、測驗與賽道功能。

## 製作順序
1. 以共用曲面建立車頭、座艙、車肩，移除拼接球體；窗戶與裝飾沿同一曲面貼合。
2. 整合車燈、進氣口、底部擾流與可選尾翼；車殼縮圖沿用同一模型。
3. 補全透視材質還原、模型測試，檢查三種車色與兩種輪徑。
4. 平板橫放檢查、實際跑圈、正式部署與截圖。

## 驗收條件
- 前／側／後有一致線條，不浮貼球狀座艙、不遮蓋導輪；30 mm 輪胎仍有間隙。
- 全部車殼材質可透視與恢復；BOM、爆炸拆解與配色仍有效。
- 1024×600、1024×768、1280×720 不產生整頁垂直捲動。
- 單一 3D 頁面驗證，不同時啟動錄影、批量瀏覽器與建置；不無限重試。

## 驗證紀錄（2026-09-08）
- TypeScript 檢查及 28 個測試檔、446 項測試通過。
- 本機實際操作：天藍／橘紅／星紫、尾翼、30 mm 輪胎、旋轉後側視角、全車殼透視、BOM 分頁與拆解、圖片測驗。
- 原理頁 1024×600、1024×768、1280×720：頁面寬高等於視窗，無下拉選單、無超出視窗的按鈕。
- 新模型實際完成三圈：16.22 秒（模擬時間）；車色不改變物理參數。
- 驗收發現拆解被裁切，已改為按零件投影範圍自動取景；再次拆開重設縮放，手動放大縮小仍保留。
- 渲染保持單一場景、30 FPS 上限、1× 像素比例；抽查記憶體餘裕 38–47%，未同時執行錄影或批量瀏覽器。
- 這是原創教學玩具造型，不是小米或 Ferrari 授權模型，也不宣稱精密工程／商業賽車模擬。
