# 教室太陽系：互動、教材圖片與影片腳本共用方案

日期：2026-09-07。狀態：設計與資料草稿，尚未實作新教室 renderer、生成教室美術、輸出教材圖片或發布新模組。原地球公轉實驗保留。

## 參考與現況

- 使用者參考：[Jared Owen — How Big is the Solar System?](https://www.youtube.com/watch?v=MK5E_7hOi-k)。已核對作者、標題並抽查行星大小比較畫面；不宣稱原影片使用 Three.js，也不下載重用原影片的模型、貼圖或配樂。
- 現有 `src/modules/earth-orbit/EarthOrbitModule.ts` 是 Pixi 與 Three.js 混合呈現；地球／月球、軌道計算及 `assets.ts` 可作重用候選，不等於已經有八行星教室。
- 現有 `src/experiments/experience.ts` 提供語音、筆記與考題體驗；先抽取可共用介面，避免把新主題硬塞入回力車的特殊 DOM。
- Three.js 的 [Scene Graph](https://threejs.org/manual/en/scenegraph.html) 支援群組與局部座標；[截圖說明](https://threejs.org/manual/en/tips.html) 與 [Render Targets](https://threejs.org/manual/en/rendertargets.html) 可用來讓同一場景輸出教材圖。

## 體驗

星際教室全景 → 點桌上的太陽系 → 鏡頭靠近模型 → 行星探索／大小比較 → 鉛筆看圖題 → 回教室。

- 教室採深藍星際牆面、暖木桌、柔和青色與金色點綴、親切的玩具教材質感。白字半透明面板與框內圖示沿用共用規範。
- 教室遠景可用生成的牆面／窗景貼圖；桌面、近處家具和太陽系是獨立 3D 物件。不能將整間教室與行星烘焙成一張圖後硬放大，否則運鏡沒有視差，近景也容易模糊。
- 使用單一渲染器，分為 classroomRoot、solarRoot、lighting、cameraRig。教室桌上模型與拉近後的模型引用同一組行星資產；移動鏡頭並依需要調整教學展示尺度，遠景教室淡出或降細節。
- 運鏡有起止鏡位與目標，緩入緩出、可略過或中斷；減少動態偏好採直接換鏡。切回教室、筆記與題目時保存探索狀態。
- 一指轉視角、點星球靠近並聽介紹；播放／暫停、重聽與重玩採圖示。無下拉選單、無下滑长頁，目標橫放尺寸按共用規範驗收。

## 素材與內容共用

`scene_spec.json + asset_manifest.json + teacher_script.json`

同一份場景資料驅動三種用途：

1. **互動實驗**：讀取物件、鏡位、模型與動作；孩子的操作改變執行期狀態，不改原始教材。
2. **教材圖片**：指定 shot ID 與固定時間，將相同模型／貼圖渲染成全景圖、近景圖或透明物件圖；自動產生學習卡及題目圖片的素材，不另生成外觀不一致的星球。
3. **影片腳本與分鏡**：每段引用同一個 shot ID、asset ID、鏡頭動作、旁白及教學提示；可輸出教師 JSON 與可讀脚本。腳本不是已完成影片；有聲影片另需核定配音、時間軸及編碼流程。

AI 用於新美術、旁白草稿及教學情境提案；不能憑空保證生成圖與 3D 模型像素一致。教學核心圖優先直接由 scene 渲染；需要 AI 補充插畫時，以批准的場景輸出與物件圖作參考，逐張審核。

## 資料邊界

- 資產以穩定 ID、版本、用途、授權／生成紀錄、透明需求、視角與狀態登記。缺素材保持 `needs-art`，不填入不存在的完成品路徑。
- 鏡位與教材畫面狀態集中於 scene spec；教師腳本只引用 shot ID，避免旁白、互動版與分鏡各自維護一組不一致的星球位置。
- 實際科學值與美術顯示值分開。軌道探索可壓縮距離、放大行星，但須標明為示意；大小比較使用統一的直徑比例。大小與距離不能混成一套假等比例模型。
- 土星環是獨立元件，不能在比較直徑時誤算成星球本體。冥王星如加入，獨立標記為矮行星，不混入八行星排序。
- 圖片輸出記錄 scene／asset／shot 版本、比例模式、時間與 seed。渲染所需貼圖先完成載入；非同源素材必須處理授權與 CORS。輸出不依賴使用者當下正在玩的隨機狀態。
- 截圖不能直接假設包含 DOM 標籤；物件版輸出透明 PNG，教材版則另由共用版面合成批准的標籤。
- JSON 只可引用白名單動作與模型，不能執行任意程式碼。未實作的場景／互動不能因通過 JSON 語法檢查就上架。

## 首支教學示範（60 秒草稿）

| 秒數 | 畫面／運鏡 | 語音草稿 |
|---|---|---|
| 0–8 | 教室全景，桌面模型輕亮 | 今天，教室裡藏著一個小宇宙！你找到桌上的太陽系了嗎？ |
| 8–18 | 鏡頭靠近太陽系，教室遠景淡出 | 靠近看看！太陽在中間，八顆行星沿著各自的軌道繞著它轉。 |
| 18–30 | 地球近景；保留太陽方向提示 | 找到藍色的地球了！這是我們的家。用手轉一轉，換個方向看。 |
| 30–44 | 同比例的地球與木星並排；圖形標記比較 | 地球和木星，哪一顆比較大？先猜猜，再看看它們並排的樣子。 |
| 44–54 | 切到鉛筆題頁：圖卡選較大的行星 | 換你試試看！點一下比較大的那顆星球。 |
| 54–60 | 回到教室，保留已探索星球的標記 | 做得好！你可以再選一顆星球，繼續探索。 |

秒數是剪輯目標，完成配音後須按實際語音時長校正，不截斷講解。互動版在選擇與作答處等待孩子；影片模式則按教學腳本播放示範，不偽造孩子的真實作答。

## 實作與驗收順序

1. 先完成教室構圖審核與必要貼圖，建立教室到桌面太陽系的第一條鏡頭路徑。
2. 接入八行星資產、點選／轉動、統一大小比較與語音；保留原地球公轉入口。
3. 實作固定鏡位 PNG 輸出、透明物件圖及腳本輸出；同一 shot 重播結果一致。
4. 加入圖片題與重玩，驗收三個橫放尺寸、貼圖完整性、手勢中斷、效能及資源清理。
5. 圖片與腳本先審核，再製作有聲影片；後台 AI 批量生成與審核發布屬後續階段，不作為目前已具備功能。
